# 秋招汇总（2026 届参考）

> ⚠️ **时效性提醒**：本文档基于 2025-2026 秋招情况撰写，**每年 5-6 月更新一次**。
> 信息来源：牛客、知乎、各公司官方公众号、朋友内推分享。

---

## 📅 秋招时间线（通用）

| 阶段 | 时间 | 任务 |
|---|---|---|
| **准备期** | 1-5 月 | 基础知识、八股、刷题 |
| **提前批** | 6-7 月 | 头部公司（华为、海思、大厂） |
| **正式批** | 8-9 月 | 集中投递期 |
| **面试期** | 9-10 月 | 笔试 + 多轮面试 |
| **Offer 季** | 10-11 月 | Offer 谈判、签约 |
| **补录** | 12-2 月 | 没招满的岗位 |

> 📌 **避坑**：H&M、字节、招行等大厂的"提前批"在 6 月就开始了，错过等于错过大半个秋招。

## 🏢 公司汇总（10 家头部，按投递热门度排序）

### 1. 华为海思（HiSilicon）

| 维度 | 内容 |
|---|---|
| **业务** | 麒麟、鲲鹏、巴龙、昇腾、AI 芯片 |
| **岗位** | 数字后端、PR、STA、PV、低功耗 |
| **地点** | 深圳、上海、北京、成都、武汉、东莞 |
| **流程** | 投递 → 笔试（部分岗）→ 技术面 ×2 → 主管面 → HR 面 → Offer |
| **考察重点** | STA 八股、CTS 流程、创新能力（解决复杂 LED 问题） |
| **薪资** | 14-16 薪，总包 30-60W（按级别 B 14+，C 16+） |
| **评价** | **卷王公司**，加班强度高；但培养体系完整，适合卷王入门 |

#### 投递技巧
- **官网 + 校园大使**：校园大使内推有加成
- **笔试**：客观题 + 1-2 道编程题
- **面试**：会问"你做过最复杂的项目"+ 八股 + LED 案例
- **加面**：部门缺人时可能加面，难度更大

#### 面经摘录
> "海思数字后端一面 60 分钟，主要问 STA 八股和项目细节，CTS 工具流程，最后给一个 LED 设计问怎么改。" ——2025 届硕士，知乎

## 📝 秋招投递 Checklist

### 投递前
- [ ] 简历优化（项目经历量化，技能关键词齐全）
- [ ] 八股刷完（至少时序、CTS、CDC 三个专题）
- [ ] 准备好 STAR 法自我介绍（3 分钟版 + 1 分钟版）
- [ ] 准备好项目介绍（每个项目 5 分钟讲清楚）
- [ ] 英文自我介绍（外企必备）

### 投递时
- [ ] **海投但不盲投**——按"冲刺 + 匹配 + 保底"三档分配
- [ ] **记录每次投递**：公司、岗位、链接、内推人、进度
- [ ] **每场面试后写面经**——整理到自己的笔记里

### 面试中
- [ ] 不要硬背答案——**理解比背诵重要**
- [ ] 项目经历问"我做了什么、为什么这么做、结果如何"
- [ ] 不会的题诚实说，转向自己会的领域
- [ ] 反问环节：问团队规模、新人培养、技术栈

### Offer 谈判
- [ ] **多个 Offer 互相 leverage**——但不要说谎
- [ ] 总包 = Base × 月数 + 签字费 + 股票 / 年分
- [ ] 关注 **Base 和股票比例**——股票可能缩水
- [ ] 关注 **加班强度、年假、培训体系**——长期福利
- [ ] 不要轻易签两方/三方——毁约要付违约金

## ⚠️ 避坑指南

1. **错过提前批**：大厂提前批占 HC 30-50%
2. **不写面经**：下次面试可能问同一个公司的新问题
3. **Offer 决策冲动**：拿到第一个 Offer 后不要立刻签——等 2 周
4. **不问 5 年规划**：HR 面常问，没想好会被认为"不稳定"
5. **不研究公司**：被问"你为什么来我们公司"答不好，直接扣分
