# 社招汇总 · 数字 IC 后端跳槽指南

> **社招 = 在职跳槽**，与校招有本质差异：社招考察深度、经验、独立性；校招考察潜力、基础、学习能力。
> 本篇覆盖：社招 vs 校招差异、跳槽时间点、猎头渠道、面试重点、级别对应、薪资谈判。

---

## 一、社招 vs 校招的 5 大差异

| 维度 | 校招 | 社招 |
|---|---|---|
| **考察重点** | 基础 + 学习能力 | 项目深度 + 独立能力 |
| **面试轮数** | 3~4 轮 | 2~4 轮（高级别更少）|
| **HR 比重** | 高 | 低（leader 决定）|
| **薪资灵活度** | 公司制度决定 | 可议价（package 谈判）|
| **入职难度** | 看 offer 数 | 看背景调查（严格）|

### 1.1 校招看潜力，社招看深度

**校招面试题示例**：
- "讲一下 setup/hold"
- "什么是 OCV？"
- "你项目中 STA 怎么做的？"

**社招面试题示例**：
- "讲一个你完整负责的 P&R 项目，遇到的最大挑战是什么？"
- "5nm 工艺 IR Drop 怎么修？具体命令？"
- "你团队有 5 个人，怎么分工？怎么 review code？"
- "为什么你们项目用 Innovus 而不用 ICC2？"
- "如果让你设计一个新流程，你怎么规划？"

**关键差异**：**校招题是"概念题"，社招题是"实战题"**。

### 1.2 校招问"是什么"，社招问"为什么"

| 校招 | 社招 |
|---|---|
| "什么是 OCV？" | "你们项目为什么用 AOCV 而不用 POCV？两者区别？" |
| "CTS 是什么？" | "你的项目 clock tree 怎么 balance？用了什么策略？" |
| "UPF 是什么？" | "你们项目 power gating 怎么实现？retention 策略？多 domain 怎么处理 isolation？" |
| "DRC 是什么？" | "你项目 DRC 失败率多少？Tapeout 前怎么确保 0 违例？" |

**结论**：社招**至少要能讲 2-3 个完整项目**，并且能讲清楚每个项目的：
- **技术决策**（为什么用这个方案）
- **遇到的问题**（怎么 debug）
- **最终结果**（量化收益）

## 二、跳槽时间点选择

### 2.1 何时适合跳？

| 时机 | 适合度 | 原因 |
|---|---|---|
| **满 1 年** | ❌ 不建议 | 太浅，议价能力低 |
| **满 2 年** | ⚠️ 谨慎 | 一定要项目亮点 |
| **满 3 年** | ✅ 黄金 | 有项目经验、议价能力强 |
| **满 5 年** | ✅ 黄金 | 高级别起点（staff 路线）|
| **满 7+ 年** | ⚠️ 谨慎 | 高不成低不就风险 |

### 2.2 一年中的最佳时机

| 月份 | 适合度 | 原因 |
|---|---|---|
| **1-2 月** | ❌ | 年终奖未发，HR 冻结 |
| **3-4 月** | ✅ | 金三银四，跳槽旺季 |
| **5-6 月** | ⚠️ | 适合校招社招并行 |
| **7-8 月** | ❌ | 暑期实习，岗位少 |
| **9-10 月** | ✅ | 金九银十，秋招季 |
| **11-12 月** | ❌ | 年底招聘停滞 |

### 2.3 业务节奏考虑

| 公司状态 | 适合跳 |
|---|---|
| 业务上升期 | ⚠️ 走前要签 NDA |
| 业务稳定期 | ✅ 最佳 |
| 业务收缩期 | ✅ 主动走 |
| 被收购期 | ✅ 把握窗口期 |

### 2.4 几个"不要跳"的情况

1. ❌ **试用期未过**（< 3 个月）——简历不好看
2. ❌ **手上项目未结**——**绝不裸辞**，会失去议价能力
3. ❌ **股票未归属**——算清账再走
4. ❌ **经济下行期**——企业招聘冻结
5. ❌ **背调有问题**——前公司关系差，跳槽困难

| **本土猎头** | 用人公司 | 高级工程师 |
| **RPO（招聘流程外包）** | 用人公司 | 批量招聘 |

**知名猎头公司**：

| 公司 | 专长 |
|---|---|
| **海德思哲（Heidrick & Struggles）** | 高管 |
| **光辉国际（Korn Ferry）** | 高管 |
| **任仕达（Randstad）** | 中高端 |
| **科锐国际** | 国内中高端 |
| **CGL（Consummate Global Leader）** | 高端 |

**与猎头打交道的 5 个 Tips**：
1. **一次只让 1-2 个猎头推你**——避免冲突
2. **明确告诉猎头你的范围**——城市、薪资、岗位
3. **面试反馈及时同步**——让猎头调整策略
4. **拒绝时给猎头反馈**——维护关系
5. **Offer 阶段保护自己**——多拿 offer 才议价

## 四、面试重点（社招专属）

### 4.1 必问的 10 道社招题

| # | 问题 | 考察点 |
|---|---|---|
| 1 | 讲一个你完整负责的项目 | 表达 + 深度 |
| 2 | 这个项目最大的技术挑战是什么？怎么解决的？ | 解决能力 |
| 3 | 你们项目的 P&R 流程是什么？为什么这么设计？ | 决策能力 |
| 4 | 你如何 debug 一个 timing 违例？ | 实战 |
| 5 | 你团队怎么分工？ | 协作 |
| 6 | 你和前端/DFT 怎么协作？ | 跨团队 |
| 7 | 你觉得先进工艺最大的挑战是什么？ | 视野 |
| 8 | 如果让你重新设计这个项目，你会改什么？ | 反思 |
| 9 | 你的 mentor 风格？你的下属怎么评价你？ | 领导力 |
| 10 | 为什么想离开现公司？ | 动机 |

### 4.2 高频深挖题

| 问题 | 答案框架 |
|---|---|
| "你的项目多少人？你的职责是什么？" | 项目规模 + 你的具体贡献（量化）|
| "你的 design size 多大？用了什么工艺？" | 数字 + 工艺 + 关键指标 |
| "Tapeout 过吗？几次？" | 真实经历 |
| "你最骄傲的项目是什么？" | STAR 法则（情境-任务-行动-结果）|
| "你最大的失败是什么？" | 反思 + 改进 |
| "你的弱点是什么？" | 真实 + 在改进中 |
| "5 年后想做什么？" | 长期规划 |

**你应该问面试官的问题**：

### 5.3 签字费谈判技巧

**签字费**（Sign-on Bonus）：社招入职时一次性发放的现金。

| 要素 | 说明 |
|---|---|
| **常见范围** | 5w~50w（看级别） |
| **支付方式** | 分 2 期（入职 + 转正后） |
| **限制条件** | 离职需退还（一般 1-2 年内） |
| **谈判空间** | 比较大 |

**谈判话术**：
- "我目前股票有 X 万未归属，希望贵司能补偿"
- "贵司 base 比市场价低 X%，希望签字费弥补"
- "我希望总 package 提升 10w，可以通过签字费形式"

## 六、薪资谈判策略

### 6.1 谈判前准备

| 准备项 | 内容 |
|---|---|
| **市场价调研** | 脉脉、offershow、看准网、知乎 |
| **个人价值评估** | 项目经验、稀缺技能 |
| **底线设定** | 最低接受、理想薪资 |
| **多拿 offer** | 至少 2-3 个 offer 在手 |
| **了解公司文化** | 不同公司谈判风格不同 |

### 6.2 谈判的 4 个原则

| 原则 | 解释 |
|---|---|
| **永远不先开价** | 让 HR 先出价，你后置加码 |
| **要 Total Package** | base + 股票 + 签字费 + 福利 |
| **不要"会考虑"** | 直接说"我接受"或"我拒绝" |
| **保持礼貌但坚定** | 不卑不亢 |

### 6.3 谈判话术示例

**情况 1：HR 给的 offer 低于预期**
> "感谢贵司的 offer，我对团队和岗位都很感兴趣。但坦白说，目前的 package 与我预期有 X 万的差距。
> 我手上有另一个 offer 提供了更好的条件，但我更看重贵司的平台。能否请 HR 帮忙争取一下？"

**情况 2：HR 坚持不涨 base**
> "我理解 base 调整有限。能否考虑：
> 1）增加签字费 X 万
> 2）入职后 6 个月有调薪窗口
> 3）增加股票授予数量"

**情况 3：HR 问你期望**
> "我看了下贵司同岗位的市场价，大致是 X-Y。我个人背景是 [亮点]，所以期望是 Y 的水平。但更重要的是平台和成长。"

### 6.4 不该做的 5 件事

| ❌ 行为 | 后果 |
|---|---|
| 拿假 offer 压价 | 背景调查会被识破 |
| 在意气用事 | 长期形象受损 |
| 全部把话说死 | 失去谈判空间 |
| 不了解公司福利 | 错过重要信息 |
| 同时面试多家冲突 | 可能被拉黑 |

## 七、背调与 Offer 处理

### 7.1 背景调查（社招必做）

**背调内容**：

| 项目 | 验证方式 |
|---|---|
| **学历** | 学信网 |
| **前公司** | HR / 前同事 |
| **职位** | HR 确认 |
| **薪资** | 薪资流水 / 前公司证明 |
| **在职/离职状态** | 社保缴纳记录 |
| **项目经历** | 前同事评价 |

**应对策略**：
1. **保持和前公司 HR 良好关系**——背调打电话是给前 HR
2. **不要过分夸大项目**——前同事背调会识破
3. **离职证明 + 薪资证明**准备好
4. **简历不写"打杂"项目**——只写能讲清楚的

### 7.2 Offer 选择的 5 个维度

| 维度 | 权重（参考）|
|---|---|
| **业务方向** | 30% |
| **薪资 Package** | 25% |
| **团队/leader** | 20% |
| **公司平台/稳定性** | 15% |
| **工作地点/生活** | 10% |

### 7.3 毁 Offer 的代价

| 行为 | 后果 |
|---|---|
| **签了 offer 后毁约** | 行业黑名单 + 法律责任 |
| **口头 offer 拒绝** | 风险低，但伤关系 |
| **背调被发现 offer 造假** | 几乎无翻身机会 |

> 📌 **建议**：offer 慎重接，**签了就要去**。

## 八、Level 提升路线

### 8.1 校招入职后的级别路线（参考）

```
校招入职 (P5/16级)
  ↓ 1-2 年: 独立负责小 block
  ↓ 3-5 年: 负责完整模块 / 子系统
  ↓ 5-8 年: 跨模块协作 / 带新人
  ↓ 8-10 年: 团队 lead / 架构师
```

### 8.2 升级答辩常见问题

| 类别 | 问题示例 |
|---|---|
| **项目贡献** | "你过去 N 年最重要的项目是什么？" |

| **影响力** | "你的工作影响了多少人？" |
| **跨团队** | "你如何推动跨团队项目？" |
| **培养人** | "你带了几个新人？他们的成长情况？" |
| **行业洞察** | "你怎么看未来 3 年的技术趋势？" |

### 8.3 高级别（Staff+）的要求

| 级别 | 关键能力 |
|---|---|
| **P7/Staff** | 1-2 个领域专家，独立作战 |

| **P9+/Principal** | 行业影响，定方向 |

## 九、社招实战案例

### 案例 1：3 年经验跳槽到外企

**背景**：
- 现公司：国内初创 AI 芯片
- 经验：3 年 7nm 工艺
- 跳槽：外企 GPU 部门

**流程**：
1. **3 月**领英联系猎头
2. **3 月底**一面（英文）
3. **4 月初**二面（lead）
4. **4 月中**HR 面
5. **4 月底**offer
6. **5 月**谈签字费、股票
7. **6 月**提离职
8. **7 月**入职

**薪资变化**：
- 原 base：45w
- 新 base：70w
- 签字费：30w
- 股票：100w（4 年 vest）

**总涨幅**：~150%

### 案例 2：5 年经验跳槽到大厂

**背景**：
- 现公司：中型 IC 设计公司
- 经验：5 年 STA 专项
- 跳槽：互联网大厂自研芯片

**流程**：
1. **1 月**开始看机会
2. **2-3 月**面试 5 家公司
3. **3 月底**手握 3 个 offer
4. **4 月初**签最心仪的

**薪资变化**：
- 原 base：80w
- 新 base：110w
- 签字费：20w
- 股票：80w（4 年 vest）

**关键**：
- 同时面试多家，议价能力提升
- STA 是稀缺技能，多家公司抢

### 案例 3：8 年经验社招到 AI 芯片独角兽

**背景**：
- 现公司：海思
- 经验：8 年 5nm 工艺
- 跳槽：AI 芯片独角兽（staff）

**流程**：
1. **猎头推荐**（高端猎头）
2. **VP 级电话沟通**
3. **CTO 面试**
4. **CEO 终面**
5. **2 周内 offer**

**薪资变化**：
- 原 base：130w
- 新 base：180w
- 期权：300w（4 年 vest + 1 年 cliff）
- 签字费：50w

**总涨幅**：~50%（但期权有想象空间）

## 十、避坑指南

### 10.1 跳槽前必查 5 件事

| # | 事项 | 怎么查 |
|---|---|---|
| 1 | 公司业务稳定性 | 脉脉、企查查、新闻 |
| 2 | 团队氛围 | 内推人/前员工/脉脉 |
| 3 | leader 风格 | 面试时观察 |
| 4 | 加班强度 | 面试直接问、看准网 |
| 5 | 现金流/融资 | 投资界、IT 桔子 |

### 10.2 跳槽中常踩的 5 个坑

| 坑 | 后果 |
|---|---|
| ❌ 裸辞 | 失去议价能力 |
| ❌ 全部押注 1 个 offer | 议价能力弱 |
| ❌ 背调前没和前公司沟通 | 背调失败 |
| ❌ 没看清合同细节 | 入职后纠纷 |
| ❌ 接受口头 offer | 变卦无据 |

### 10.3 跳槽后融入的 5 个 Tips

| Tip | 说明 |
|---|---|
| **第 1 个月：多听少说** | 了解团队运作 |
| **第 2 个月：找 1 个小项目立威** | 展示能力 |
| **第 3 个月：建立人脉** | 跨团队 |
| **第 4-6 个月：拿到关键项目** | 巩固位置 |
| **第 7-12 个月：产生业务价值** | 转正/晋升 |
