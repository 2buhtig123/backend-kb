## 🎯 这是什么

一份**面向求职者**的公开知识库——区别于各类碎片化的面经/博客，我们希望做到：

1. **结构化** — 按"知识体系 + 招聘节点"两条轴组织内容，能搜索、能筛选
2. **时效性** — 招聘信息按季度更新，不做"过期古董"
3. **可验证** — 每个八股题都有"参考答案 + 真实案例"双栏，避免纸上谈兵
4. **可贡献** — 接受社区 PR（脱敏后），共建可持续更新的求职 Wiki

## 🗺️ 推荐学习路线（3-6 个月速通）

> 假设你是电子/微电子/通信/CS 相关专业在校生，目标拿到数字后端方向秋招 offer。

### 第 1 个月：打地基
- [ ] CMOS 与数字电路基础（必读）
- [ ] 阅读一本入门书（《数字集成电路：电路、系统与设计》/ 《CMOS VLSI Design》任一）
- [ ] 学会 Linux 基础 + tcl 脚本
- [ ] 在 EDA Playground / 开源 PDK（Sky130）跑通一个简单反相器综合

### 第 2 个月：核心技能
- [ ] 静态时序分析（STA）— 必读 5 节
- [ ] 工具上手：Innovus / ICC2 任选其一（公司用什么学什么）
- [ ] 跑通一个完整 RTL → GDSII 流程（开源 PDK + 开源 EDA）

### 第 3 个月：进阶 + 实习
- [ ] 时钟树综合（CTS）— 必读
- [ ] 低功耗设计（UPF）
- [ ] 投递暑期实习（3-5 月）

### 第 4-6 个月：投递秋招
- [ ] 物理验证（PV）+ Sign-off
- [ ] 八股题库刷题（每天 5 道）
- [ ] 7-8 月开始秋招投递
- [ ] 复盘 + 模拟面试

## 🌐 在线站点

本知识库已配置好完整的 Astro 站点（位于 `site/` 子目录）。

### 本地预览

```bash
cd site
npm install
node scripts/migrate-content.mjs   # 同步内容到 src/content/
npm run dev                        # http://localhost:4321
```

### 构建生产版本

```bash
npm run build    # 输出到 site/dist/
```

构建产物 1.5MB（含 Pagefind 搜索索引），可直接托管到任何静态网站服务。

### 一键部署

| 平台 | 难度 | 推荐度 | 备注 |
|---|---|---|---|
| **EdgeOne Pages** | ⭐ 最简单 | ⭐⭐⭐⭐⭐ 国内用户 | 自动识别 Astro，关联 GitHub 仓库即可 |
| **Vercel** | ⭐ 最简单 | ⭐⭐⭐⭐⭐ 海外用户 | 国际化访问稳定 |
| **GitHub Pages** | ⭐⭐ 需配置 | ⭐⭐⭐⭐ 已有 `.github/workflows/deploy.yml` | 速度在国内一般 |
| **Netlify** | ⭐ 简单 | ⭐⭐⭐⭐ | 同 Vercel 体验 |

#### EdgeOne Pages 部署步骤

1. 把仓库推到 GitHub
2. 访问 https://edgeone.ai/pages 用 GitHub 登录
3. "Create project" → 选择你的仓库
4. 配置：
   - **Framework preset**：Astro
   - **Build command**：`cd site && npm install && node scripts/migrate-content.mjs && npm run build`
   - **Build output directory**：`site/dist`
   - **Node version**：22
5. 点 "Deploy"，2-3 分钟上线

#### 自定义域名

部署后在 EdgeOne Pages / Vercel 控制台添加 CNAME 记录即可，建议用 `.com` 或 `.io` 域名（避免 ICP 备案麻烦）。
