# 物理验证（PV）：DRC / LVS / ERC 与天线检查

> **什么是物理验证？** 物理实现完成后，必须验证物理版图是否正确。
> 这道门**通过才能流片**——一次流片失败动辄损失百万美元。
> 数字后端的 "PD / CTS / PV" 三角，PV 是 Sign-off 的最后一步。

---

## 1. 三大物理验证

| 验证 | 全称 | 检查内容 |
|---|---|---|
| **DRC** | Design Rule Check | 几何规则（间距、宽度、密度） |
| **LVS** | Layout vs Schematic | 版图 vs 网表一致性 |
| **ERC** | Electrical Rule Check | 电学规则（电源、地、闩锁） |

其他还有 **ANT（天线效应）**、**DFM（可制造性）**、**ESD** 等。

---

## 2. DRC（Design Rule Check）

### 2.1 什么是 DRC？

检查版图是否违反工艺厂提供的**几何规则**。规则由工艺厂定义，目的是保证**可制造性**和**良率**。晶圆代工厂对不同工艺参数制定出满足芯片制造良率的同一工艺层及不同工艺层之间几何尺寸的最小值，借由 EDA 工具将这些最小值规划的设计规则小值集合通过指定语法转成可执行的设计规则文件（design rule deck 或 command file）对版图进行检查（《数字集成电路物理设计》p.25）。书中同时提醒：设计规则并不代表芯片制造成功与失败的硬性分水岭——违反某些规则的版图流片后仍可能正常工作，满足所有规则的版图也不一定能够正确工作（p.25）。

### 2.2 典型规则类别

| 类别 | 示例 | 典型值（28nm） |
|---|---|---|
| **宽度 (Width)** | Metal 线宽 ≥ 0.06 µm | 0.06-0.1 µm |
| **间距 (Spacing)** | Metal-to-Metal 间距 ≥ 0.06 µm | 0.06-0.1 µm |
| **重叠 (Overlap)** | Via 覆盖 metal ≥ 0.02 µm | 0.02-0.05 µm |
| **面积 (Area)** | Metal area ≥ 0.1 µm² | 0.1-0.5 µm² |
| **密度 (Density)** | Metal density 30-70% | 30-70% |
| **Enclosure** | Metal 1 必须完全包住 via | 0.02-0.03 µm |

### 2.3 DRC 类别细分

书中的数字 IC DRC 检查分两步（《数字集成电路物理设计》p.27）：

- **顶层 DRC 检查**：将布局布线后的顶层 GDSII 文件与晶圆厂的设计规则（通过 LEF 文件传递）做初步检查
- **全芯片 DRC 检查**：将包括顶层和所有底层单元的 GDSII 文件打平，根据设计规则文件进行最终的完整 DRC 检查

### 2.4 DRC 修复

工具跑完 DRC 后输出违例位置 + 规则名：
```
RULE_M1_SPACING < 0.06
LAYER M1
VIOLATION 0.04
COORDINATE (100.5, 200.3)
```

修复策略：
- **Spacing 违例**：把过近的线移开
- **Width 违例**：加宽线
- **Area 违例**：加大面积
- **Density 违例**：加 dummy metal

### 2.5 工具
- **Calibre**（Siemens EDA，原 Mentor Graphics）— 业界最常用
- **Pegasus / PVS**（Cadence）
- **IC Validator**（Synopsys）

书中（成书年代）列出的 DRC/LVS 检查工具：最早的物理验证工具 Dracula 由 ECAD 公司开发并于 1983 年作为产品问世（后并入 Cadence）；此外还有 Cadence 的 Assura 和 Diva、Mentor 公司的 Calibre、Synopsys 公司的 Hercules（《数字集成电路物理设计》p.25）。

寄生参数提取（不属于 DRC）：StarRC（Synopsys）、QRC（Cadence）

> **面试考点**："你做过 DRC 吗？" → 答 "Calibre + 修复过 [X 类] 违例" 比 "我没做过 DRC" 强 10 倍。

## 3. LVS（Layout vs Schematic）

### 3.1 什么是 LVS？

对比**版图提取的网表** vs **和**原始门级网表**，确保一致。书中把 LVS 概括为"先抽取、后比较"两步：先根据 LVS 提取规则从版图中抽出版图所确定的网表文件（晶体管级 SPICE 网表），再把它与门级 Verilog 网表（需结合 SPICE/CDL 模型转化为 SPICE 网表）做逻辑等效性比对（《数字集成电路物理设计》p.29）。

```
Layout → 提取 → 网表_extracted
                         ↓ LVS
                Netlist_original（综合 / RTL）
```

### 3.2 LVS 检查项

1. **Device 一致性**：晶体管数量、类型一致
3. **Net 一致性**：连接关系一致
3. **Pin 一致性**：端口定义一致
4. **Power/Ground 一致性**：电源地连接

书中将 LVS 检查内容概括为两点：所有信号的电气连接关系是否一致、器件类型尺寸是否一致（《数字集成电路物理设计》p.28）。

### 3.3 LVS 错误类型

| 错误 | 原因 |
|---|---|
| **Missing device** | 版图漏画器件 |
| **Extra device** | 版图多了器件 |
| **Shorted nets** | 应断开的 net 接在一起 |
| **Open nets** | 应连接的 net 没接上 |
| **Property mismatch** | 器件 W/L 不一致 |

（《数字集成电路物理设计》p.30-31）

### 3.4 LVS 修复

书中给出的 LVS 排错顺序：先查器件数目，再依次查器件类型、节点数量、电源线和地线的连接，最后从关键点找起。值得注意：版图节点数多于原理图，通常说明版图中存在开路；节点数少于原理图，则可能存在短路（《数字集成电路物理设计》p.30-31）。

- **Shorted nets**：检查 DRC 是否提示；多半是 over-connection
- **Open nets**：检查 missing via；可能漏画 metal
- **Property mismatch**：版图 W/L 标错

书中还提到：工具做 LVS 前会对版图中的器件做归一化处理（normalizing），把版图中折叠、并联或串联的器件（如画图折叠成多指的 MOS 管）合并成一个再比较；器件名称不一致但功能相同时，可用捆绑文件（binding file）解决（《数字集成电路物理设计》p.30）。

## 4. ERC（Electrical Rule Check）

书中把 ERC 看作 **LVS 功能的一个子集**：主要用于检查没有电路意义的连接错误，但不涉及具体的电路行为检查，如电源、接地、输入、输出端分别用特定的文本层标出节点名称后，ERC 判断文本名称与内部节点数之间的关系确定电路是否有电学规则违反。由于利用 LVS 工具可以检查电学规则违反，现在很少把 ERC 作为一个单独的验证步骤来做（《数字集成电路物理设计》p.31）。

闩锁、天线效应等可靠性问题由专门检查覆盖，见下文第 5、6 节。

## 5. 天线效应（Antenna Effect）— 重点

### 5.1 什么是天线效应？

芯片制造过程中，**等离子刻蚀**会让长的 floating metal 累积电荷。
- 如果 metal 接到 MOS 栅极，累积电荷会击穿栅氧
- 类似"避雷针"原理——长 metal 像天线

书中（深亚微米芯片制造）表述：金属连线从第一层开始再向上层加工完成，等离子刻蚀被广泛采用，这种工艺会使用刻蚀过程中收集大量空间游离电荷；当金属积累的游离电荷超过一定数量，形成栅极所承受的击穿电压时，晶体管就会被击穿，即工艺天线效应（process antenna effect，PAE）（《数字集成电路物理设计》p.51）。

### 5.2 Antenna Ratio

```
Antenna Ratio = (金属面积) / (连接到栅的面积)
```

- 阈值由晶圆厂在规则文件中给定，书中 LEF 示例为 AntennaAreaRatio 10000、AntennaSideAreaRatio 5000（《数字集成电路物理设计》p.51）
- 越长越细的 metal，越容易违例
- 天线面积有两种算法：平面面积（draw area）与侧面面积（side area）。先进工艺下金属厚度比宽度大许多，现代工艺多采用侧面积去做标志并对门栅保护（《数字集成电路物理设计》p.51-52）
- EDA 工具通常采用两种模型计算天线比率：部分检查模型（partially checking model，PAR）与累积检查模型（cumulative checking model，CAR），CAR 是所有相关层 PAR 的和（《数字集成电路物理设计》p.52）

### 5.3 修复方法

| 方法 | 适用 | 缺点 |
|---|---|---|
| **跳线 (Jump)** | 中高层 metal | 多走一段线，拥塞 |
| **插 Antenna Diode** | 任意 | 占面积，泄漏 |
| **改 routing 层** | 高层 | 资源紧张 |

```
违例：  A -----long wire----- Gate（长 metal）
修复：  A -----first layer--- Diode --- Gate
```

书中把解决天线效应的方法归纳为两种：插入天线二极管，以及中断金属连线跳换布线层（layer hopping）（《数字集成电路物理设计》p.53）。二极管通常在布线完成后加在违反天线规则的栅输入端，把加工过程中金属层积累的电荷释放到地端以免器件失效（p.41）。

## 6. 闩锁（Latch-up）

### 6.1 什么是闩锁？

CMOS 工艺中的寄生 **PNPN**（晶闸管结构）：

```
VDD ---- P+ ---- N-well ---- N+ 
                  │
                  └─ P-sub ---- P+ ---- GND
```

- 正常时 PNPN 不导通
- 异常时（如过压、电流注入）：PNPN 触发导通
- **大电流直接流过 VDD → GND**——可能烧毁芯片

书中解释其机理：n 阱 CMOS 中寄生双极晶体管与 p 型衬底双极晶体管构成正反馈回路，产生闩锁的最根本原因是两个寄生晶体管的电流增益乘积大于 1，使电流不断放大；要减小闩锁效应必须降低寄生双极晶体管的基极偏置电压、减小基极偏置电阻和两管增益值（《数字集成电路物理设计》p.21-22）。

### 6.2 防止方法

1. **Guard Ring**：N 阱 + N 接触（NMOS 周边）
3. **足够间距**：NMOS 离 P+ 远
3. **Tap Cell**：均匀分布 N+/P+ tap
4. **避免过压**：IO 防护
5. **SOI 工艺**：用 SOI 材料代替硅材料使晶体管与周围器件相隔离，从根本上消除闩锁效应（《数字集成电路物理设计》p.22-23）

CMOS 中普遍采用的预防方法即增加 well tap 或保护环：NMOS 管周围形成接地的 p+ 区、PMOS 管周围形成接电源的 n+ 区，可极大降低寄生电阻的值（p.22）。

## 7. ESD（静电防护）

### 7.1 什么是 ESD？

人体静电可至 **数 kV**，芯片 IO 必须能承受。

### 7.2 ESD 保护电路

- **GGNMOS**：栅接地 NMOS
- **GDPMOS**：栅接电源 PMOS
- **RC 触发 SCR**

### 7.3 ESD 设计窗口

```
HBM (人体模型): 通过 +/−2kV（安全 +/−4kV，最佳 +/−10kV）
MM (机器模型): 通过 +/−200V（安全 +/−400V，最佳 +/−1kV）
CDM (充电器件模型): 通过 +/−1kV（安全 +/−1.5kV，最佳 +/−2kV）
FIM (电场感应模型): 与 CDM 放电模式相似
```

（《数字集成电路物理设计》p.38-39，表 2-6）

```
PNR 完成（gds + 网表 + DEF）
     ↓
 DRC + Antenna 全芯片跑
     ↓
 修复 → 反复迭代
     ↓

     ↓
 ERC + ESD 检查
     ↓
 DFM 检查（推荐）
     ↓
 交付 Foundry 签核
```

## 11. 实战建议

1. **Calibre 跑完整 DRC/LVS 一次**：在 PNR 后第一时间
2. **Antenna 违例在低层最常见**：插 diode 比 plug cell 是大
3. **Density 必须修**：否则良率受影响
4. **LVS 跑通不等于 DRC 跑通**：两者必须都过
5. **Foundry 签核反馈**：注意 DRC rule 版本对应

## 12. PV 常见面试题

### Q1：DRC 违例修不完怎么办？

**答**：
- 按违例密度分类：高频 vs 偶发
- 高频：修 floorplan / placement / 走线规则
- 偶发：手动修
- 最后剩下用 waiver（与 foundry 商量豁免）

### Q2：LVS 报 shorted net，怎么排查？

**答**：
- 用 Calibre RVE 高亮 shorted net
- 看 layout 是不是哪里有 spurious via / over-connection
- 抽查定义映射是否对

### Q3：Antenna 违例 fix 方案？

**答**：
- **跳线** (preferred)：换到高层走线
- **Diode**：插 antenna diode cell
- **跳线 + diode 组合**

### Q4：为什么 DRC 必须 0 违例？

**答**：DRC 是工艺厂给的可制造性规则，违例意味着：
- 良率下降
- 芯片可能失效
- 工艺厂会拒绝签核
