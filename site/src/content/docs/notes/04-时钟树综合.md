本篇为《数字集成电路物理设计》第 4 章（p.93-127）的浓缩笔记，可与原书对照阅读。原书 4.1 讲时钟信号本身，树形与网状结构在 4.2.2；本文沿用原书编号。

时钟是数据传输的基准，通常是芯片中扇出最大、走线最长、速度最高的信号，必须在最差条件下满足时序要求，否则错误数据会被锁存进寄存器（p.93）。标准单元 ASIC 流程中，综合阶段把大时钟网络当理想时钟，物理设计阶段才做 CTS，之后改为传播时钟分析（p.93、p.100）。

## 4.1 时钟信号

### 4.1.1 系统时钟与时钟信号的生成

系统时钟控制多个芯片之间的时钟网络与相互时序，单芯片内的时钟称全局时钟（p.93）。全局时钟由片上 PLL 产生，PLL 在 SoC 中常作为硬核集成在芯片内部；输出 `f_out = f_ref × M/N × 1/(1+k)`，k 取 0 或 1，M、N 可编程（p.94）。DLL 用 VCDL 代替 VCO，优点是工艺变化不相关、能减小抖动；Xilinx 的 FPGA 就在芯片四角布置全数字 DLL，每个 DLL 驱动多个全局时钟网络（p.94）。环形振荡器由奇数个反相器构成，周期由级数和每级延迟决定，稳定性差，只用于性能要求不高的设计（p.95）。两相时钟可由传输门或 RS 触发器产生，分频时钟一般由触发器产生（p.95）。

### 4.1.2 时钟信号的定义

周期（频率）、延迟、不确定性是时钟的三要素（p.95）。表 4-1 把时钟定义为源、周期、波形、上升沿、下降沿五项，上升/下降沿指 0→1、1→0 的转变时间（p.96）。SDC 对时钟的定义分三部分：时钟定义、latency（4.1.3 节）、uncertainty（4.1.4 节）（p.96）。例 4-1 至例 4-4 依次给出 20ns/50MHz 基本时钟、30% 占空比、不等宽脉冲和 2/4/8 分频时钟的写法（p.96）。

### 4.1.3 时钟信号延迟

latency 又称 insertion delay，由时钟源插入延迟与时钟网络插入延迟组成：前者是系统时钟或晶振到芯片/模块时钟根节点的延迟，后者是根节点到寄存器的时钟树延迟，总插入延迟为二者之和（p.97，图 4-11）。理想时钟假定网络插入延迟为零；CTS 时 latency 数值直接用于偏差的计算和固定（p.97）。源延迟定义到芯片顶层时留给板级设计人员使用；定义到模块层次可满足模块间特定的时序先后要求（p.97）。书注指出，有的教科书只考虑理想时钟，把 latency 与 skew 直接联系起来，本书的约定不同：根到寄存器的延迟叫 latency，同一时钟到任意两个寄存器的延迟差叫 skew，时钟本身的 jitter 与 uncertainty 叫抖动和不确定性（p.97 注）。

### 4.1.4 时钟信号抖动

jitter 是信号时间与理想事件时间的偏差，含确定抖动 DJ 与随机抖动 RJ；参考点常取 50%，DJ 来自串扰、电磁干扰、SSO，RJ 服从高斯分布（p.98）。度量分边到边 `J_ee`、k 周期 `J_k`、周期间 `J_cc` 三种，式（4-1）用标准差定义（p.98）。jitter 由时钟发生器结构决定，PLL 中电源波动会直接传到 VCO，环形滤波可减小其影响（p.98）。jitter 又称 uncertainty；CTS 无法优化它，只能考虑其影响，故抖动是先天存在的、不确定性是人为定义的（p.98）。逻辑设计阶段 uncertainty 设得较大，给 skew 留范围；CTS 后按工艺与设计设小，书中示例取 0.3ns（p.98）。

### 4.1.5 时钟信号偏差

skew 指同一时钟到达时钟域内不同寄存器的时间偏差：

`skew = max|t_i - t_j|`，`0 < i < n`，`0 < j < n`

t_i、t_j 为根节点到叶节点 i、j 的时间（p.99）。按此定义 skew 是无符号的差值；实际偏差有正负两种（图 4-14），正偏差与负偏差对 setup、hold 的影响不同，4.4.1 节再展开。到得最早的叶节点时间称最小插入延迟，最晚的称最大插入延迟，两者之差为最大偏差（p.99，图 4-15）。偏差分布近似正态；CTS 前要给出最大偏差，CTS 后时钟改为传播时钟，用实际延迟分析（p.100）。

例 4-5 给出把预期偏差放进 uncertainty 的做法（p.99）：0.18μm、1.8V 的 SoC，最快时钟 250MHz、最慢 12MHz；250MHz 的 skew 目标为 0.2ns，12MHz 为 0.4ns，时钟抖动为 0.1ns。时钟树综合前把 uncertainty 设为目标 skew 与抖动之和：250MHz 取 0.3ns，12MHz 取 0.5ns。CTS 后实测叶节点 skew 为 0.1ns，再把 uncertainty 降为 0.2ns。这样先用 uncertainty 模拟预期偏差，CTS 后再按实测结果收紧，偏差目标就被参数化地控制住了。

插入延迟也有取舍：延迟大则 buffer 多、偏差小但功耗大；延迟小可能满足不了偏差。两个时钟域之间需要相位差时，也用延迟调节（p.100）。

## 4.2 时钟树综合方法

真实时钟分理想时钟（CTS 前）与传播时钟（CTS 后）；虚拟时钟没有源头，用于相对系统参考、当前设计中不存在的时钟，CTS 必须先定义虚拟时钟再约束端口（p.100）。

### 4.2.1 时钟树综合与标准设计约束文件

SDC 由时钟定义、输入延迟、输出延迟三部分组成，顶层还要约束端口驱动与负载（p.101）。表 4-2 把约束分为时钟定义、延迟定义、驱动定义和特殊路径四类；多时钟 SoC 还要设多周期路径、伪路径等特殊约束（p.101）。输入/输出延迟用于端口时序匹配：min 条件一般查 hold，max 查 setup（p.101）。驱动可用 BUFFER 或电阻定义，顶层典型值 0.05kΩ，模块级常用 BUFX2；输出负载以 pF 计，CPU 总线、PCI、SDRAM、LCD 控制线的经验值为 30pF，USB 取 60pF，模块内部一般不超过 0.5pF（p.102）。

### 4.2.2 时钟树结构

root pin/root cell 是起点，中间节点为分布单元，寄存器时钟端为叶节点（leaf cell）；从根逐级插 buffer/inverter 到叶，按约束产生时钟树的过程即 CTS（p.103，图 4-19）。早期在逻辑综合时做时钟树并 dont_touch；1995 年后改在布局布线中综合，综合阶段按理想时钟、物理阶段按传播时钟分析（p.103）。

树形结构中，H-tree 到各叶节点距离相等，理论上零偏差；缺点是布线困难、难以协调一致，只适合较小的设计（p.103）。X-tree 同样追求等长，但用了大量非 90° 互连，扇出为 4，H-tree 为 2（p.103）。tapered H-tree 把分支后线宽减半、电阻变为分支前的 2 倍，以减小叶节点反射电流（p.104）。平衡树用两个层次驱动：顶层一级驱动平衡模块间偏差，模块内再插一级平衡，适合分层次、较大的时钟树（p.104）。书中列出的结构还有梳状（comb）与脊椎状（spine）时钟网，脊椎状实例即图 4-31 的 Pentium 4 三级脊椎树（p.103、p.110）。

网状结构中，clock mesh/clock grid 是获取较小时钟偏差的实用方案；EDA 能自动生成网格拓扑，但仍需经验和细致的手动调整（p.104）。书中没有单列“混合结构”，混合形态见图 4-29(b)：第一节为 buffer 链（Top Chain），第二节为 H-tree（书中亦称鱼骨状，图中标为 Global Mesh），第三节为局部时钟树（Local Tree）（p.109）。根节点负载很大时用多个 buffer 并联驱动，STA 对这种平行 buffer 算不准，需要 SPICE 仿真（p.109）。

### 4.2.3 时钟树约束文件与综合

每个时钟树要定义名称、周期、根节点、最大插入延迟、最大偏差、max transition，并可指定专用 buffer/inverter；约束文件可由 SDC 自动产生（p.104）。例 4-6 给出 min_delay 2.0、max_delay 2.5、max_skew 0.1、max_transition 1.0，并用 excluded_pins 排除测试引脚（p.105）。流程从标准单元布局开始：先算根到各叶的延迟，再插 buffer 减小并平衡延迟；布局工具摆正 buffer，布线前用估算的互连延迟，布线时优先布时钟树，避免最大偏差等参数被破坏（p.105）。

## 4.3 时钟树设计策略

### 4.3.1 时钟树综合策略

自我交叉指 PLL 时钟经分频或控制后由 mux 汇合。工具先平衡右侧 tree，再均衡 circuit1 与 circuit2（p.105，图 4-22）。相互交叉中，tree3 是 wb_clk 与 lcd_clk 经 mux 的公共段：先综合 tree3，再 tree1（同时平衡其内部偏差与到 mux 的延迟），最后 tree2（同时平衡自身及与 tree1 的偏差）；两时钟频率相差大时，按快速时钟的要求统一目标（p.105-106，图 4-23）。

有用偏差（useful skew）针对“零偏差”提出：零偏差不一定性能最好。datapath 组合延时大、寄存器时钟延时小，迁就长路径而增加寄存器时钟延时不影响功能，这就是有用偏差（p.106，图 4-24）。做法是在 CTS 前加快源时钟，CTS 后加填充单元（padding cell）减慢靶时钟（p.106）。算例：T=4ns，F1-F2 组合延迟 3.3ns，F2-F3 为 4.3ns，门延迟 0.1ns，setup/hold 0.1ns，时钟到达均为 1ns；两条路径的 slack 分别为 +0.5ns 与 -0.5ns。把到 F2 的时钟从 1ns 改为 0.5ns，skew 变为 0.5ns，两条路径 slack 都变为 0（p.106-107，图 4-25）。这就是通过填充单元（padding cell）增加延迟来平衡 skew 的实用做法。

OCV 在纳米工艺下已不可忽略：同一 BF2 在相同输入与负载下标称 0.29ns、实际 0.25ns（p.107，图 4-26）。CLKBUF #2 偏快会引起 setup 违例，CLKBUF #1 位置不正常会引起 hold 违例（p.107-108）。书中用 scaled OCV，对 setup/hold 各加 20% 预算：early path 取 0.8~1.0，late path 取 1.0~1.2（p.108）。共享 BUFIX 在时钟路径标定 0.8、数据路径标定 1.0，形成“悲观时钟收敛”，用 CPPR/CRPR 去除共同路径的悲观量（p.108）。

手动 CTS 适用于熟悉设计的情况：按模块关系手动摆叶节点，先在小范围综合各模块时钟、指定 buffer 级数与每级驱动的叶节点，再在顶层平衡全局时钟。CPU 例子中 mul、alu、fmul、falu 手动插树，cache 由工具自动插树，顶层用模块时钟模型拼接；手自动结合可省时间、减小偏差和 buffer 数量（p.108-109）。

### 4.3.2 时钟树案例

实际 H-tree 并不完全对称（p.109）。Pentium 4 2GHz 用三级脊椎型时钟树，180nm 工艺，多用手动方法（p.109-110）。Alpha 21064、21164、21264 的主频分别为 166MHz、300MHz、600MHz（p.110）。21064 一级线驱动，中心偏差小、四周大范围内偏差大，最大 500ps；21164 改二级线驱动，靠近二级驱动线的范围偏差小、四周小范围内为 300ps；21264 先用 6 级强 buffer，再把芯片分四区做时钟网格，约 50ps，较大偏差集中在芯片中心较小的范围（p.110-111）。1.2GHz Alpha 用 DLL 稳定时钟并采用多个时钟网格，偏差降到 30ps（p.111）。聚芯 SoC-1000（0.18μm）cpu 时钟 200MHz，一级总线时钟比 cpu 晚 0.2ns，二级总线比一级晚 2ns（p.111）。

### 4.3.3 异步时钟树设计

同步流水线各级都在同一时钟下工作，级间组合逻辑 L1、L2……Ln 的延迟被约束在一定范围内，时序正确性容易保证；同步时钟树结构简单、鲁棒、易验证，但大时钟物理实现难，封装电感与电源电阻在同时钟跳变时产生很大噪声。异步电路各级有自己的局部时钟，通过异步握手传递请求与应答，电路不规则，但速度快、功耗低；异步应答信号要当特殊时钟处理，把全局时钟拆成多个局部时钟后，CTS 反而方便（p.112-113）。

### 4.3.4 锁存器时钟树

锁存器在半周期内透明，可做时间借用（time borrowing）。F1→L2→F3 流水中，L2 为锁存器时，组合逻辑 A 的条件由 `τ_A < T - t_clkdel - t_setup` 变为

`τ_A < T - t_clkdel - t_setup + t_borrow`，`0 < t_borrow < T/2`

B 的条件相应减去 t_borrow（p.113）。借用可逐级传递，若流水线全由锁存器组成，时间可以一级一级借到最后一级（p.113-114）。实验报道频率加快 15%，但增加功耗（p.113）。锁存器对毛刺透明、抗噪差，一般不提倡，只有在经验足、物理设计有抗噪措施时才用（p.114）。

### 4.3.5 门控时钟

门控时钟用一个控制信号控制时钟的开启，模块不工作时关时钟，从而降低触发器的总翻转率（p.114）。按关闭范围分粗、中、细粒度。粗粒度用一个门控单元关整个模块，门控单元放在靠近根节点处，时钟树好做，几乎所有低功耗设计都会采用；细粒度十几个到几十个触发器一个门控，门控单元大量分布，CTS 要特殊处理（p.114）。简单与门门控有竞争冒险，常用锁存器加与门构成（p.114，图 4-38）。

建立时间：EN 经 t_ck-q 与线延迟 t_w3 到与门 A 端，`t_en_n = t_en + t_ck-q + t_w3`；时钟经 t_w1 到 B 端，下一周期检查点为 `t_clk + t_w1 + T`，要求

`t_en + t_w3 + t_ck-q < (t_clk + t_w1 + T) - t_setup`（4-2）

（p.115）。EN 逻辑一般不深，setup 通常能满足，不是关注重点。

保持时间：要求 `t_en_n - t_clk_n > t_hold`，展开为

`(t_w1 + t_w3 + t_ck-q) - t_w2 > t_hold`

（p.116）。EN 到得太早会在时钟上产生毛刺。若 buffer 插在 w1 与 w2 交汇点之后，B 端时钟更晚，容易 hold 违例；工具为修 hold 会在锁存器与与门之间插 buffer，增加功耗和面积。正确做法是把 buffer 插在 w1 与 w2 交汇点之前（p.116，图 4-42）。现在的 EDA 工具能识别门控时钟，并穿过门控时钟到达时钟树的叶节点（p.116）。

## 4.4 时钟树分析

### 4.4.1 时钟树与时序分析

建立时间：无 skew 时 `T_cycle = t_clk-q + t_dmax + t_setup`（4-3）；有 skew 时

`T_cycle = t_clk-q + t_dmax + t_setup + t_skew`（4-4）

（p.116-117）。图 4-43 用“本周期晚时钟”发射、“下周期早时钟”捕获标出最坏组合：发射晚到、捕获早到，可用时间少一个 skew，等效于所需周期加 t_skew，频率随之下降（p.117）。

保持时间：无 skew 时 `t_hold < t_clk-q + t_dmin`；有 skew 时

`t_skew + t_hold < t_clk-q + t_dmin`

（p.117）。图 4-44 用“下周期早时钟”发射、“本周期晚时钟”捕获：数据早到、捕获沿晚到，保持裕量被吃掉一个 skew。组合逻辑越浅（t_dmin 越小）越容易 hold 违例；降频不能修 hold，而加大 t_dmin 会增加面积、布线和功耗（p.117-118）。

把两式放在一起看，同一个无符号 skew 对 setup 和 hold 的作用方向相反：setup 怕发射沿晚、捕获沿早，hold 怕发射沿早、捕获沿晚。因此判断违例时不能只看一个 skew 数值，还要看该寄存器在路径上是发射端还是捕获端（p.117，图 4-43、图 4-44）。

### 4.4.2 时钟树与功耗分析

时钟树功耗含静态、短路、跳变三部分：

`P = P0 ΣK_i + (1/12)κτf_clk(V_DD - 2V_T)^3 + αf_clkC0V^2L(T)`（4-5）

（p.118）。其中 P0 是尺寸最小 buffer 的静态功耗，K_i 是第 i 个 buffer 相对最小 buffer 的尺寸倍数，N 为插入的 buffer 总数；静态项随 buffer 加权数增加。短路项与 transition 成正比、与 V_T 的三次方成反比；跳变项由门加权数和互连电容决定，时钟树跳变功耗接近芯片的 50% 或更高（p.118）。降功耗的方向是最小化 `L(T) + αΣK_i`，即少插 buffer、插小 buffer、缩短走线（p.118）。

约束上，目标偏差 δ 一般不超过时钟周期的 10%，严格时 2%；transition 按 10%~90% 定义，最大转换时间不超过时钟周期的 10%，0.18μm、1.8V、200MHz 下常取 0.3ns（p.119）。该值也不能设得太小，否则插入的 buffer 数量增加，面积和功耗上升，甚至工具无法完成 CTS（p.119）。节点电容要小于 C_max，近根用大驱动、近叶用小驱动（p.119-120）。例 4-14：16 点 H-tree 线长 1.5D√N，Steiner 树为 D√N，后者省 30% 走线（p.121）。

### 4.4.3 时钟树与噪声分析

时钟翻转率最高，噪声要单独看。两类机制：数据 D 端的耦合尖脉冲在时钟上升沿被触发器采到；时钟下降沿上耦合出上升脉冲，把 D 端数据错误传到 Q 端（p.121-122）。抑制方法有三种：局部电源/地屏蔽（接地电容增大延迟、占布线空间，只适合局部）；提高驱动能力（选 BUFX8 以上，噪声容限更高）；高层金属加多倍间距（线电阻低、电容小）（p.122）。书中特别提到晶振到 PLL 的参考时钟：布局时让晶振与 PLL 尽量近，参考时钟周围加一圈电源屏蔽线，避免被 PLL 输出的高频时钟干扰，倍频时钟的稳定性也随之得到保证（p.122）。

耦合噪声 `ΔV2 = C_cΔV1/(C_gnd + C_c)`，与 C_c 成正比（p.123）。耦合电容分面积、侧向、边缘三部分：面积电容 C_A 是不同层金属对应面之间的电容，侧向电容 C_L 是同一层金属侧面积引起的电容，边缘电容 C_F 是不同层金属不同侧面之间形成的电容，其值分别为 `C_A = ε_oxW/H`、`C_L = ε_oxT/S`、`C_F = ε_oxln(1+T/H)`（p.123）。0.18μm 与 0.13μm 下侧向电容占总电容的 50%~80%（p.124）。双倍间距把耦合电容降到 64%/62%，三倍降到 52%/50%，四倍降到 46%/44%，但占用布线资源；双线宽双间距为 75%/73%；书中认为双倍间距是折中较好的方案（p.125-126）。

## 4.5 本章总结

本章归纳为六组：时钟与时钟生成（系统时钟与全局时钟、PLL/DLL）；时钟参数（周期、负载因子、漂移、抖动）；时钟树特征（插入延迟、最大偏差、有用偏差、最大转换时间）；时钟树类型（H 树、X 树、平衡树/梳状/脊椎状、网状树）；时钟树设计（同步、异步、寄存器、锁存器、门控）；时钟树综合策略（自我收敛、交叉时钟、有用偏差、CPPR/CRPR）（p.126）。书末强调，布局完成后要提供完整的数据环境供 CTS 使用，除物理库、时序库、设计数据与约束外，还要有时钟信号特征、时钟树类型和约束参数（p.126）。
