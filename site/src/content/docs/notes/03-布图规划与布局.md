本篇为《数字集成电路物理设计》第 3 章（p.56-92）的浓缩笔记，可与原书对照阅读。原书小节为：3.1 布图规划（3.1.1 内容与目标、3.1.2 I/O 接口单元的放置与供电、3.1.3 方案与延迟预估、3.1.4 模块布放与布线通道）；3.2 电源规划（3.2.1 电源网络设计、3.2.2 数模混合供电、3.2.3 时钟网络、3.2.4 多电源供电）；3.3 布局（3.3.1 展平式、3.3.2 层次化、3.3.3 目标预估、3.3.4 优化算法）；3.4 扫描链重组；3.5 网表文件；3.6 总结。


布图规划与布局的合理与否直接关系到芯片的时序收敛、布线通畅、电源稳定和良率；从布图规划到完成布图一般占整个物理实施 1/3 的时间（p.56）。布图规划又称标准单元放置，包括 I/O 单元的排序放置、大模块放置和标准单元位置的规划。布图规划、电源规划与布局通常连续进行而工程上穿插反复。开始时需准备六类数据（表 3-1）：设计网表、设计约束文件（.sdc）、物理库文件（.lef）、时序库文件（.lib）、I/O 约束文件、布图要求文件（p.56）。

标准单元占芯片面积 50% 以上，故标准单元布局是布图过程的重要部分。读入设计后工具按 Verilog 层次逐级分解顶层模块，图 3-1 中标出顶层模块及利用率 70.3%，四周 I/O 管脚已布好，四个角落的方块是 corner 单元，用于连接四周管脚形成的电源环（p.56-57）。

### 3.1.1 布图规划的内容和目标（p.57-58）

内容包括芯片大小（die size）规划、I/O 单元规划、硬核或模块的规划等；不规则设计需对布线通道作特殊设置，超大规模设计中为减小时钟偏差还要在布局前规划时钟网络，其分布与普通时钟树不同（p.57）。

目标有四：①确定芯片面积——面积大则每片 wafer 的 die 数少、成本高，但面积过小会造成拥塞、难以布线、导致长周期迭代，故最初目标是估计面积；②确保时序收敛——寄存器间路径长短决定性能，需按 SDC 约束预估延迟（见 3.1.3）；③保证芯片稳定——I/O 单元的静电保护与供电设计是稳定条件，3.1.2 的电源规划保证内部供电均匀；④满足布线要求——方便走线、保证布通、缩短走线以减小互连延迟，这要求设计者了解模块间连接关系与数据通路结构（p.57-58）。

### 3.1.2 I/O 接口单元的放置与供电（p.58-60）

I/O 单元是芯片内部信号与封装管脚之间的桥梁，其分配要综合印制板走线、封装形式、供电情况和内部模块结构，使信号从内部到外部路径最短，并避免关键引线到封装点时信号交叉，以方便封装基板制作、减少走线层数、降低封装成本（p.58）。

类型有数字与双向输入输出、静电保护、给 I/O 与给芯核供电、数字与模拟填充、模拟输入输出、专用输入输出和角填充单元等，按驱动能力（0.18μm 为例）分 1mA、2mA、4mA、6mA、8mA、12mA、16mA。SMIC 0.18μm 1P6M 库有普通宽度、狭窄宽度、宽宽度 3 种：I/O 多而内部逻辑少（I/O 限制型）选狭窄型，反之选宽型；同等条件下狭窄型更高。子模块的 I/O 形式为接点（pin）而非接口（pad），ASIC 中为提高利用率可把每一边的单元先做成一块模块（图 3-2）（p.58-59）。

芯片面积大（如大于 1cm×1cm）、时序紧张时用倒置封装（flip-chip），I/O 均匀分布在芯片内部（图 3-3）。步骤：①在 LEF 中用 `CLASS PAD` 与 `PAD SITE` 定义 I/O 类型；②导入 flip-chip 的 I/O 库；③加载版图规划文件与 I/O 设置文件；④放置 I/O 单元（p.59）。

电源 I/O 单元分三类：给模拟器件供电、给数字器件供电、隔离数字与模拟供电。模拟器件的供电单元须用指定类型并在两端加隔离单元，一般一个模拟器件用一对；I/O 较宽松时最好「双绑定」，即 die 上两个单元绑到一个焊盘上（p.59-60）。数字 I/O 单元分两组，分别给 I/O 与核内标准单元供电。给核内供电的 I/O 数量按式（3-1）估算（p.60）：

```text
m = P_avg / (V_pad · I_pad) · k          (3-1)
```

`P_avg` 为芯片平均功耗，`I_pad` 为供电 I/O 单元最大电流，`V_pad` 为正常供电电压，`k` 为调整因子，最小取 1~2、最大可取 5~10。数量还受 I/O 功耗、驱动能力、同步开关噪声（SSN）与 SSO 影响；经验值为给 I/O 供电的单元数与输出信号端口数之比 1:(5~10)，与给内核供电的单元数之比 1:2。摆放要考虑电压降（IR drop），一般在电源环设计完成后做功耗分析选定；翻转率高、频率高的端口放在供电单元周围以降低噪声（p.60）。

### 3.1.3 布图规划方案与延迟预估（p.61-65）

规划前先对时序做零线负载模型（zero WLM）延迟分析，验证刚综合出的网表；若理想情况下时序已紧张、剩余时间（slack）较大，应重新优化网表或从 RTL 着手缩短关键路径（p.61）。设计方法分自下而上展平式（flatten，SVP 硅虚拟原型）与自上而下层次化；芯片在 500 万门左右时因时序收敛复杂性和缩短周期的需求会考虑层次化方案。

展平式设计先实验多种布图规划，再据标准单元布局做静态时序分析，用负的剩余时间评估哪种规划合理。延迟由门延迟与线延迟组成，因尚未建立互连线，只能由 WLM 按门的扇出（FO）估算互连线长度再折算电容（图 3-5）（p.61）。

层次化设计分三步：顶层设计规划、子模块分割（partition）与实现、顶层组装。时序预估含对整个芯片的延迟预估与时序分析、子模块约束的产生，后者在延迟预估和时序收敛的前提下进行。图 3-6 流程：设计输入→布图规划→顶层标准单元快速预布局及优化→快速预布线及优化→延迟估算及时序分析→是否满足时序（否则回退）→给各子模块分配边界约束（p.62-63）。

时序预算：先确认穿过各分割区域的时钟并产生其传播延迟；再确定各区域的所有边界接点，按通路延迟大小对应所属时钟域，输入接点生成 `set_input_delay`、输出接点生成 `set_output_delay`。多条路径经过同一单点会产生时序竞争（图 3-7），工具按用户指定路径解决，选项有 `-min`、`-max`、`-critical`、`-multiclock`、`-normalized`、`-combined`；用 `set_max_delay`/`set_min_delay` 通过多时钟域端口时优先于输入输出延迟（p.63-64）。

展平式在规划与布局阶段以定义的时钟延迟和不确定性模拟时钟，层次化则须在顶层预估并分配时钟树延迟。图 3-8 中 clk1 总延迟理想值 1.2ns，按各子模块面积与挂接寄存器数量分配为 0.2ns、0.5ns、0.3ns，顶层到子模块 1 与子模块 3 到输出各 0.1ns；`-source` 定义从时钟源头到时钟树根节点的延迟，也可直接定义时钟树上的延迟（p.64-65）。

### 3.1.4 模块布放与布线通道（p.65-67）

模块布放属布局却在规划阶段完成；因其占空间大，只有它们布完电源规划才有实际意义。当代 SoC 可含数百个以上模块，须借助工具自动布局（如 MasterPlan）。布放结果直接影响规划目标，能否布通要通过通道分析判断（p.65）。

读入数据与 die size 后，工具按 LEF 中的布线间距（pitch）生成各金属层连续、规则的布线轨道；布线轨道（routing track）是专门用于布线的路径，布线通道（routing channel）是两条或多条轨道之间的空间，其上不可放标准单元。RAM 四周常预留仅供布线、不许放单元的晕道（halo）：标准单元已占据底层金属的多数轨道，晕道可增添底层通道解决局部拥塞（图 3-10），但又会造成其他区域拥塞，故需多次迭代（p.65-66）。

层次化设计要对各分割区域之间定义通道，宽度估算考虑模块布局的拓扑约束，含子模块界限及彼此距离、顺序和排列，以及表面比率、网络权重与隔离区（图 3-11 按实例单元列出到 bot/top/left/right boundary 的距离，单位 μm）。通道按形状分 T 形与 L 形，需均衡、排序和切割以保证布通性；子模块跨度大时还需定义直通（feedthrough）通道。基于行的布线比模块间布线省空间，故层次化也引入无通道（channel-less）分割法（图 3-12）。子模块完成布局布线并满足时序后可导出 LEF 与 lib（或 ILM），成为硬核，可视为展平式中基于模块的设计（BBD）（p.66-67）。

## 3.2 电源规划（p.67-78）

电源规划是给整个芯片供电设计一个均匀网络，在布图规划后或规划过程中交叉完成，贯穿整个设计。原书本节分电源网络设置、数模混合供电、单/多电源供电三部分，其中环线与条线设置是主要工作（p.67）。供电通过 I/O 单元实现，首先要做电源预算（power budgeting）：商用产品惯例认为总误差应控制在 ±5% 之内，即电源网络与 PCB 板级到封装 bonding 间约 ±1%，电源 I/O 单元与电源环间约 ±1%，直至标准单元的电压降约 ±3%（p.67）。

### 3.2.1 电源网络设计（p.68-74）

针对 I/O 四方分布的数字芯片，内容包括：①电源连接关系定义（global net connect）；②核内电源环（power ring）；③硬核（RAM、ROM、IP、COT 等）电源环；④核内纵横交错的电源网格（power stripe）；⑤供电单元与环的连接；⑥内部网格与硬核环的连接（ring pins）；⑦标准单元供电网络与核内网络的总连接（followpins）；⑧I/O 供电单元电源环。最后检查短路、开路和供电不足，Flip Chip 还包括电源凸点 bump 的设计与布线（p.68）。

全局连接把端口与网络接到合适的电源/地网络，信息一部分在 Verilog 网表、一部分在 LEF：用 `wire` 定义电源与接地网络，用 `1'b0`、`1'b1`、`supply0`、`supply1` 定义接高/低电压网络，端口名称如 `VDD`、`VSS` 在 LEF 中定义（p.68-69）。

电源环是包围标准单元、为均匀供电的环形金属，也是连接供电 I/O 单元与标准单元的桥梁：I/O 单元经金属连到环，标准单元经 followpins 连到环。电源网格用于平均分布电流、缩短电流回路，在减小电压降的同时避免电流不均造成的热点（hot spot）与电迁移（EM）。环有 3 个参数：宽度 w、间距 d、对数 n，宽度按式（3-2）估算（p.70）：

```text
w = I_p / (C_a · 4n) · k          (3-2)
```

`I_p` 为芯片峰值电流，`C_a` 为厂家工艺库给出的电流密度上限，`n` 为环数，`k` 为调整因子。间距按设计规则的最小间距决定，一般取最小间距的 2 倍左右；也有工程师主张减小间距以增大耦合电容、过滤噪声。宽线需打孔散热，厂家会制定宽线规则：希望单环宽度不超过该规则以避免打孔（打孔又称 slotting），更好的办法是 splitting（图 3-15）。层数多时可用多层金属以减小环宽与占用面积。例 3-3 的参数为环宽 34、偏移 0.23、间距 8（p.70-71）。

硬核与 RAM 的环按硬核供电电流设定，方法与核内环相同；硬核往往自带电源环，顶层只需把网络连到其内部环。硬核需编译，厂家通常给出峰值电流限度、平均电压降限度、峰值电压降限度 3 种算法并取最大值（p.72）。

电源条线常设计成 V_DD 与 V_SS 交替排布（图 3-17），4 个参数为纵向宽度 W_stripe-V、横向宽度 W_stripe-H、两个方向的间距 S1 与 S2。纵向宽度与 S1 成正比，线宽大则间距可大、分布可稀疏；横向宽度较小、间距也小，分布需密集；横向虽同样正比于 S2，但因有大量 followpins，所需条线比纵向少很多（p.72）。三条经验规则（p.72-73）：①W_stripe-V 的分布间隔取垂直布线 pitch 的整数倍以充分利用通道，且不超过最小二输入与非门宽度的 4 倍；例 3-5 中 Metal2、Metal3 的 pitch 均为 0.66，线宽取 0.66 的整数倍。②W_stripe-V 最大值取库中最小与非门宽度的 4 倍：例 3-6 中该宽度为 1.98、4 倍为 7.92，故用 Metal2 做纵向线时取 0.66~7.92 之间 0.66 的整数倍；利用率高、拥塞大时选细密网格。③W_stripe-H 取标准单元高度的整数倍，通常 1 或 2 倍：单元高 5.04，则横向宽度取 5.04 或 10.08，拥塞不大取 2 倍、有拥塞取 1 倍。

层选择上纵向必须用偶数层、横向必须用奇数层；高层金属寄生电阻小，可有效减小电压降。SMIC 6 层工艺展平式设计时用第 4、6 层走纵向、第 5 层走横向；层次化设计在模块级用第 2、4 层纵向、顶层用第 6 层纵向与第 5 层横向（p.74）。书中数值：SMIC 0.18μm 1P6M 中 Metal1 线宽 0.23，Metal2~Metal5 为 0.28，顶层 M6 为 0.44；Metal1 与 Metal3 的 pitch 为 0.56，Metal2 与 Metal4 为 0.66，Metal5 与 Metal6 分别为 1.12 和 1.32（p.73）。

确定线宽后算间距。由功耗 P 求总电流并分配到网格：`I_total = P/V_DD`；`I_up = I_bottom = I_total·W/(W+H)`，`I_left = I_right = I_total·H/(W+H)`（3-3）。设 A 点有 5% 电压降，则 `R_effective-V = 0.05×(V_DD/2)/I_up`、`R_effective-H = 0.05×(V_DD/2)/I_left`（3-4）；`R_stripe-V = R□V·H/W_stripe-V`、`R_stripe-H = R□H·W/W_stripe-H`（3-5）；对数 `N = R_stripe-V/R_effective-V`、`M = R_stripe-H/R_effective-H`（3-6）；间距 `S1 = W/N`、`S2 = H/M`（3-7）。经验值：TSMC 0.18μm 工艺 S1、S2 为 100~200μm（W_stripe-V 取二输入与非门宽度的 4 倍左右，W_stripe-H 取标准单元高度）；0.13μm 工艺为 50~100μm（W_stripe-H 取单元高度的 2 倍）（p.74）。

### 3.2.2 数字与模拟混合供电（p.75-76）

即使纯数字芯片也常用模拟 PLL 作时钟发生器，SoC 中数模混合更普遍，需建立不同电源区域（power domain）。布局前的一般处理：①模拟模块放在芯片某角落，多个模拟单元相对集中，中间不混放数字模块；②模拟区域单独供电，给模拟信号供电的 I/O 单元放在模拟模块边上以缩短线路；③在模拟模块周围布置保护隔离环（guarding ring）。图 3-19 中 PLL 在右下角且该角 I/O 均为模拟端口，周围放低频模块；模拟供电在内部、数字供电在外部并加保护环隔离（p.75-76）。

### 3.2.3 时钟网络（p.76）

当时钟要求苛刻（如 1GHz 射频时钟无法靠自动时钟树综合实现）时，需像电源网络一样在布图规划阶段单独设计：找到时钟入口并选定位置，手动插入强驱动的 clock buffer，从其输出端画出一级驱动网络，再按需插入二级缓冲器，直至满足要求。

### 3.2.4 多电源供电（p.76-78）

MSV（multi-supply voltage）原用于数模混合，指多组同样电压（如均 1.2V）供给不同电路；低功耗设计更多采用多组电源多组电压（MSMV），关键模块用高电压、频率较低的模块用低电压，是有效降低功耗的方法。

每个电压域都须有完整的电源和地线环。可用自动供电网络设计工具（APP，automatic power planner）为每个电压域指定模板：①创建芯片核心电源环（与单电源环同法，但多对供电、占用面积较大）；②为每个电压域与硬宏单元创建模块环——须先定义各域的工作电压与所含模块，网络不匹配时工具会警告；③为宏单元创建模块环（p.77）。不同电压区之间需插入电平转换单元（VLS，voltage level shifter），先读入相应的单元表再插入；存在被关闭的电压域时，须在所有接口处添加隔离单元（isolation cell）（p.77）。

大多数模块级或芯片级 DRC/LVS 错误由供电问题引起：工具按规则抽取电源，结构相同的电源部分难以识别。故用 sign-off 工具做 LVS 时可删除电源和接地网络以外的单元与模块，单独运行针对供电网络的 DRC/LVS 检查（图 3-21）（p.78）。

## 3.3 布局（p.78-83）

I/O 单元与模块的布放已属布局范畴，但在规划阶段完成，故布局的剩余任务主要是标准单元的布局（p.78）。

### 3.3.1 展平式布局（p.78-79）

布图规划完成整体规划，布局是其细节实施，且是自动化的。内容有二：①模块的摆放与布局——历来由设计者半自动放置、不理想时重新调整，随 BBD 的使用，大量模块位置改由工具自动完成；②标准单元的摆放和优化——硬核位置设定后把模块内标准单元摆到相应位置，这是布局的主要工作，位置确定后布线后互连线寄生参数的数值才有实际意义。大量标准单元由自动布局完成，也可用脚本或手动把寄存器按阵列摆放（如 Datapath）（p.78-79）。

### 3.3.2 层次化布局（p.79-80）

层次化布局三过程：①先分配子模块，这是与展平式最大的不同；②作子模块级布局，方法同展平式；③各子模块完成后在顶层组装。子模块约束有三种（p.79）：

| 约束 | 含义 |
| --- | --- |
| 向导约束 guide | 属该模块的单元可在范围内也可在外；不属该模块的单元也可放入 |
| 区域约束 region | 属该模块的单元只能放在指定区域内，该区域还可放其他模块单元 |
| 限制约束 fence | 属该模块的单元只能放在该区域内，且不许放其他模块的单元 |

限制型是强约束，多用于层次化设计，展平式多用较宽松的约束。名称出自 Cadence SoC Encounter，其他工具定义有别，如 Astro 用 PlanGroup、以权重确定约束程度（p.79）。

模块大小主要看面积利用率，即标准单元总面积与模块在芯片内部所分布面积之比：初始利用率低于 70% 时较容易布通，高于 85% 时则出现较大拥塞、导致无法完成布线（p.79）。例 3-9 中 I2 所在电压域跨过电源环，向下拉伸后与 S2 上侧边保持 10μm 左右，故用 fence；例 3-10 中 I1 所分配面积较小、利用率高导致拥塞大，增高后布局得到优化（p.79-80）。

### 3.3.3 布局目标预估（p.80-82）

布局完成后要评估的目标有三：①各模块位置相对确定，每个标准单元都放在相应位置并具有自己的状态（attribute），全局拥塞均匀合理、基本满足布通；②满足设计规则，除时钟网络外的高扇出网络（如复位）都插入驱动单元，满足最大电容、最大扇出与最大信号转换时间等约束，时钟网络规则留待时钟树综合；③时序与供电良好——布局后可按具体位置用较精确的延迟模型预估，有时布线后延迟比布局后高出 5%~10%；保持（hold）时间违例一般在时钟树综合之后完成（p.80-81）。

拥塞预估：工具把布线空间划分为多个布线格，每格分横向与纵向通道，统计每格所需通道数；当实际需要的通道超过现有通道的 5% 时，表明拥塞程度比较大。全局拥塞很小但局部拥塞较大、造成无法布通时，需优化标准单元布局（p.81）。

时序预估只做建立（setup）时间预估，不做保持时间预估。噪声方面，0.18μm 及以上工艺一般不需太多考虑，0.13μm 及以下则需考虑，在布局阶段即可考虑（p.81）。供电预估：把标准单元供电端口连到电源网格（followpins）后，可引用 VCD 文件评估功耗、电压降与 EM；因时钟树尚未综合，功耗值会偏小（p.81-82）。

### 3.3.4 标准单元布局优化算法（p.82-83）

模块的面积约束指定后，标准单元的放置与优化由工具自动完成。从步骤上布局分三个阶段：结群布局（clustering）、全局布局（global placement）、详细布局（detailed placement），各有相应算法（p.82）。

结群算法最早为 Breuer's algorithm，核心是选一个单元作种子（seed）并不断结合与其最紧密的单元；现在较普遍应用的是模拟退火（simulated annealing），按「能量函数」随机移动，其最佳答案为「最小全局」布局方案。其他分割算法有 K-L 算法（Kernighan-Lin）、F-M 算法（Fiduccia-Mattheyses）与比率分割算法（Ratio-Cut）。全局布局（含布图规划）主要采用最小切割法（Breuer 算法的直接应用）、模拟退火（Kirkpatrick 算法的直接应用）、贪婪算法（greedy）、力向量法（force directed）、NRG、HA-LO 等（p.82）。

按对象分 3 种：纯标准单元布局、模块布局（macro-cell placement）、混合单元布局（mixed-size placement）。应用最广的仍是纯标准单元布局，RAM 等硬核大都手动布局；越来越多 CPU 采用以模块为主的设计（BBD），100 多个模块手动布局需数小时，而模块布局法（MasterPlan）仅需数分钟；混合单元布局尚未广泛应用，又被归类到布图规划设计中（p.82）。

按优化目标分 3 类：基于布线拥塞的布局（routability-driven / congestion-driven placement）、基于时序的布局（timing-driven placement）、预防噪声的布局（crosstalk-aware placement）。拥塞驱动在工具（如 Qplace）中一般为默认选项；发现局部拥塞时可用递增布局（incremental placement）局部调整。时序驱动以实现时序为首要目标，分以路径为基础（path-based）与以网线为基础（net-based）两类。噪声驱动自 0.18μm 设计提出，早期在布线阶段考虑或布后手动处理，当代则在布线时即考虑噪声（p.82-83）。

## 3.4 扫描链重组（p.83-88）

扫描链是 DFT 的重要内容，把普通寄存器换成扫描寄存器并首尾串接；它由 DFT 工具在综合阶段产生，物理设计阶段需定义扫描链（以起点终点定义或读入综合导出的 DEF），其绝大部分单元是同一个标准单元（p.83-84）。

扫描链重组（scan chain reorder）是在不影响逻辑功能的前提下，把随机分布的扫描寄存器按物理位置重新连接以缩短走线，在时钟树综合完成后进行；它可减少内核限制型设计的拥塞，图 3-25 中重组前链长 1 134 876 484μm，重组后 121 176 528μm，约为原来的十分之一（p.84-85）。

## 3.5 物理设计网表文件（p.88-89）

该阶段的数据格式主要有 4 种：DEF、PDEF、SPF 和 SDF；SPF 与 SDF 在第 6 章讨论，PDEF 已停用。DEF（design exchange format）是展平式设计网表文件，应用最广、由 Cadence 早期推出。它是带物理信息的网表：除 Verilog 的连接信息外，还含芯片面积（布图规划后的记录）、布图规划区域定义、电压域定义（电源规划后的记录）、标准单元行、单元位置属性、端口位置信息（布局后的记录）、布线内容与特殊网线连接（布线后的记录）。多电压域时可分别导出各域电源线的 DEF 再读入，多平台交替也以 DEF 交换数据。PDEF 是 Synopsys 的同类格式，现已停用；SPF 与 SDF 分别记录 RC 参数与延迟信息（p.88-89）。

## 3.6 总结（p.89）

本章阐述布图规划与布局的内容、目标与实现方法，着重电源规划的重要性和实际方法，通过时序预估、电源分析与时序分析尽早发现问题并保证后续收敛。随着倒置封装、SiP 中的二维 MCM 与三维多芯片模块封装、TSV 连接的多芯片产品等新型封装技术的应用，布图规划与布局的实施将迎来新的革新和影响（p.89）。
