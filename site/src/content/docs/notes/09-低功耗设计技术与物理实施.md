## 9.1 低功耗设计方案综述

为了实现集成电路的低功耗设计目标，需要在系统设计阶段就采用低功耗设计方案。随着设计流程逐步推进，到了芯片设计实现阶段，能够降低芯片功耗的方法会越来越少，可节省功耗的百分比也不断下降，设计的主要目标将侧重于如何把设计方案变成物理实现（p.201）。图 9-1 以倒金字塔形式示意了从系统设计与算法级到芯片生产各级所能获得的功耗降低比例：越靠近前端，可选方案越多；越靠近物理实现，低功耗手段越受已确定的设计结构约束（p.201）。

集成电路设计流程中，系统设计到逻辑综合由 RTL 网表传递，逻辑综合到物理实现由门级网表传递，布局布线后逻辑验证和形式验证由门级网表传递。低功耗设计同样需要一种统一的功耗约束文件，即通用功耗格式 CPF（common power format），在整个流程中传递低功耗指标和参数（p.201）。表 9-1 列出了不同设计阶段可以采用的低功耗设计方法与文档文件（p.201-202）。

CMOS 电路功耗可分为动态功耗与静态功耗。动态功耗包括器件本征电容和负载电容充放电产生的开关功耗 P_sw，以及由于输入信号跳变导致 NMOS、PMOS 同时导通而形成的短路功耗 P_sc；静态功耗为逻辑门处于静态时由 pn 结反向漏电流、亚阈值电流、栅泄漏电流等引起的泄漏功耗 P_leakage。单个逻辑门的泄漏功耗虽小，但对千万级门则不可忽略；到 90nm 节点后，泄漏功耗逐渐赶上并超越动态功耗，成为功耗主体，由此产生了多阈值电压 MTCMOS 技术（p.202）。总功耗为：

P_total = P_sw + P_sc + P_leakage = α·C_L·V_DD²·f_clk + V_DD·I_sc + V_DD·I_leakage　　（9-1）

由式（9-1）可知，功耗与供电电压 V_DD 密切相关，降低功耗最有效的方法是降低供电电压，这催生了电源关断 PSO 和多电源多电压 MSMV 技术。动态功耗还与负载电容、电路频率和跳变因子有关；随着器件尺寸缩小，器件电容减小，但工作频率和信号跳变频率不断提高，因此要在频率和跳变频率上寻求减小动态功耗的方案，这就产生了动态电压与频率调节 DVFS 技术（p.202-203）。

### 9.1.2 低功耗设计代码编写

在 RTL 级代码编写阶段，为减小信号跳变频率，可采用优化的状态编码技术和编码方法。例如，对嵌入式系统算法编码压缩降低比特翻转可降低功耗达 35%；对地址数据总线编码降低 I/O 端口翻转可达 30%。这些方法包括：Bus-Invert（BI）编码、自适应（semi-adaptive）编码、Gray-Code 编码、零转换（T0，zero transition）编码、用于外部地址总线的工作区编码（WZE，working-zone-encoding）等（p.203）。编码方案选择得当，电路可以更简单；选择不当则会增加电路复杂性、器件数量和功耗消耗。

以零翻转地址总线编码为例，它通过对二进制地址总线编码，使地址连续变化时总线总翻转率为 0（图 9-2），适用于片外地址总线或宽度在 32 位以内的 SoC 内部地址总线（p.203）。

在 RTL 代码编写阶段还可采用使能信号，隔离不必要的信号跳变。图 9-3 的操作数隔离技术（operand isolation）利用使能信号和 EDA 综合工具，可避免不必要的加法器操作而产生功耗（p.203）。例 9-1 给出了一段 Verilog 描述：

```verilog
module test(en,a,b,c,out);
  input en;
  input [7:0] a,b,c;
  output [8:0] out;
  assign out = en ? a + b : a + c;
endmodule
```

当 en 无效时，通过选择操作数避免 b 或 c 参与运算所引起的不必要翻转（p.203-204）。

### 9.1.3 低功耗设计逻辑综合

逻辑综合工具在逻辑映射阶段可通过降低电路的节点翻转率或降低节点负载电容，达到降低功耗的目的（p.204）。

1. 门的合并与组合：将节点翻转率较高的逻辑门合并到复杂的门电路中，从而降低节点等效电容。图 9-4 示例中，总功耗从 0.95mW 降至 0.85mW（p.204）。
2. 优化门的大小：选择节点电容较小的门可降功耗，但副作用是电路时序性能会受到影响（图 9-5）（p.204-205）。
3. 管脚优化：将翻转率较高的信号接到输入电容较小的管脚上。图 9-6 中优化后的电路功耗比原电路降低了 0.3mW（p.205）。
4. 逻辑重建：在保证功能一致的前提下调整结构，使内部节点翻转率明显减小（图 9-7）（p.205）。

### 9.1.4 低功耗设计测试

由于当代芯片速度和片上逻辑单元密度的剧增，可测试性设计 DFT 和分析成为必不可少的步骤；但大量测试电路的增加使测试功耗成为额外负担（p.205）。降低测试功耗的方法有：减小芯片端口数以降低端口翻转数；重新分割或分配 ATPG 与存储器 BIST 以降低峰值功耗；设计 DFT 时产生低功耗测试向量（p.205-206）。

产生低功耗测试向量要求 ATPG 能分析功耗，并可用 CPF 文档控制 ATPG 的生成，对测试芯片进行自动化处理，达到节省功耗的目的（p.206）。

### 9.1.5 低功耗设计功能验证

低功耗设计中通过逻辑重组和门控关断等方式引入了新的设计方法，为避免逻辑错误，需在低功耗逻辑升级完成后进行功能验证，包括以下三方面（p.206-207）：

1. 等价检查：比较 RTL 与门级网表逻辑是否一致，检查门控时钟、门控信号传递、克隆门控时钟逻辑是否正确；应用 SRPG 时检查从 RTL 到门级网表的综合是否正确；运用 MSMV 时检查添加隔离单元和电平转换单元后的网表是否与原始 RTL 一致（图 9-9）。
2. 功能与结构检查：检查低功耗逻辑单元的插入与连接是否正确、不同电压区域之间的信号隔离单元和 SRPG 形式是否正确（图 9-10）。
3. 晶体管级检查：检查不同区域处于开关状态时的潜在功耗泄漏。如图 9-11，当电源域 A 开通、B 关断时，A 的 V_DD 可经 Y-A-D 或 Y-A-D-B-Z 到 V_SS 形成泄漏或放电通路（p.207）。

## 9.2 低功耗设计的基本方法

低功耗设计的基本方法包括：面积优化、纳米技术中引入的多阈值电压技术、时钟门控电路（p.208）。

### 9.2.1 面积优化

RTL 逻辑综合的主要目标包括优化时序、功耗和面积；在物理实施阶段，同样需要优化芯片总面积和芯核面积以进一步减小功耗。在时钟树综合时，可通过约束文件加速时钟信号传输、减小时钟树总功耗，并优先选用反相器而非缓冲器，以减小时钟树上逻辑门的面积（p.208）。但芯片面积往往受封装约束，通过减小面积降低功耗的效果比较有限（p.208）。

### 9.2.2 多阈值电压

在低功耗设计中通过减小泄漏功耗，例如采用多阈值器件 MTCMOS 技术，是较好的低功耗设计办法（p.208）。其思想是：在关键路径使用低阈值电压的逻辑器件，非关键路径使用高阈值电压的逻辑器件。阈值电压 V_TH 较高的单元漏电流小、速度慢，适合非关键路径；阈值电压较低的单元漏电流大、速度快，适合关键路径。综合工具在有多阈值单元库支持下，根据时序路径自动选择或替换阈值，以满足设计目标同时尽可能降低漏电流（p.208）。

### 9.2.3 门控时钟

时钟信号贯穿整个芯片，在存储单元时钟输入端周期性跳变，驱动负载电容大，产生较大动态功耗。借助门控时钟插入技术可减小不必要时钟跳变而产生的功耗（p.208）。例 9-2：

```verilog
module test(En,data,clk);
  input En,clk;
  input [7:0] data;
  output [7:0] out;
  reg [7:0] out;
  always@(posedge clk)
    if(En) out <= data;
endmodule
```

综合工具自动插入门控时钟（图 9-12）（p.208-209）。实现时打开门控时钟综合选项，指定门控单元类型、扇出及动态功耗目标即可自动生成（p.209）。门控时钟插入需要考虑测试问题，在时钟树综合阶段也需特殊处理（p.209）。低功耗时钟树综合技术 LP-CTS 利用最优化时钟门布局及克隆与反克隆等方法，在确保时钟功率优化的同时满足时序和物理目标，达到更好的负载分配并减小时钟传输时间（图 9-13）（p.209）。

## 9.3 低功耗设计的先进方法

先进低功耗设计方法包括：多电源多电压技术 MSMV、电源关断与状态保持电源门控技术 SRPG、动态电压与频率调节技术 DVFS。从系统架构设计、功能验证到物理实施过程，若运用 CPF，整个流程将更加顺畅（p.209-210）。

### 9.3.1 多电源多电压

多电源多电压 MSMV 可有效降低动态功耗。所谓多电源，是指不同逻辑模块处于不同电源域中，由不同供电电源供电（p.210）。物理布图阶段在核心区创建电压域，每个电压域只包含属于该域的模块或单元；不同电压域中的逻辑需与相应时序库对应，在时序、功耗分析和优化中选择正确单元库（图 9-14）（p.210）。完成电压域、I/O 和宏单元摆放后，要为每个电压域规划电源网络，设置自己的 Ring 和 Stripe（p.210）。

MSMV 布线要求同一电压域内单元互连线保持在当前域内，不同电压域之间互连线不要跨越第三方电压域（图 9-15），可用 Cadence NanoRoute 命令：

```tcl
setNanoRouteMode -routeWithHonorPD
```

（p.210-211）。

多电压技术使某些模块工作于较低电压，更易受电压降影响。静态电压降通过优化电源网络解决；动态电压降通过在电源和地之间插入去耦电容（decoupling capacitance）解决，但去耦电容会增加泄漏功耗，需在性能与功耗间权衡（p.211）。

MSMV 与 PSO 的物理实现需要两种特殊逻辑单元（p.211）：

- 电平转换单元（level shifter）：无逻辑功能，用于不同电压域之间信号电平转换，通常有两个供电电压端口分别连接两个不同电压域的供电电压（图 9-17）。
- 隔离单元（isolation cell）：起不同电压域之间的电位钳制与隔离作用，置于电压域边界，详见 9.3.2 节。

同时采用 PSO 与 MSMV 时，两个不同电压域之间不仅需要电平转换单元还需要隔离单元，有些标准单元库提供组合了两种功能的单元（图 9-20）。综合时用 CPF 定义不同电压域模块所用的工艺库名称，EDA 工具自动插入隔离单元和电平转换单元（图 9-21）（p.212-213）。

### 9.3.2 电源关断与状态保持电源门控

电源关断技术 PSO 是最早提出的节省功耗技术，其实际应用需通过状态保持电源门控 SRPG 方案实现（p.212）。PSO 是降低泄漏功耗最有效的方法，通过关断芯片中暂时不需要区域的供电实现；其实现引入电压域概念，并需仔细规划开启和关断转换周期，防止电流过冲、避免电路损坏，同时权衡关断时节省的功耗与开启时消耗的开关功耗（p.212）。

可关断电压域关断后，应在其输出端口插入隔离单元（图 9-19）。隔离单元一般采用两输入与门/或门，一个输入端连接控制信号 sleep；当 sleep 为低电平时输出固定低电平，避免未知状态 X 作为下游常开域输入而引起反复翻转与不必要的功耗（p.212-213）。

为快速唤醒，需在关断周期中保存模块重要信息。SRPG 是在原有主从寄存器基础上，使主寄存器和从寄存器工作在不同电压下：主触发器（master FF）供电由精细结构电压门控制，连接正常电压；从触发器（slave FF）连接常通的低供电电压，在电压关断后保存数据，重新上电后恢复保存值（图 9-23）（p.213-214）。

精细结构门控晶体管尺寸需折中：太大会增大面积、延迟、紧缩布线资源；太小则影响抗噪声性能与可靠性，甚至导致电路无法工作（p.213-214）。

粗制结构门又称全局电压门，利用开关单元控制整行标准单元与电源/地线轨道的连接。开关单元晶体管宽/长比较大，每行单元采用缓冲链依次关闭和开启，以避免过冲电流烧毁芯片（图 9-24）。插入方式有环形开关与柱形开关两种：环形开关在电压域内电源环与供电网络之间插入开关单元；柱形开关用开关单元控制每行标准单元与电源网络是否连接（图 9-25）（p.214-215）。

### 9.3.3 动态电压与频率调节

动态电压与频率调节 DVFS 可看作 MSV 的扩展，已在 Intel Xscale、Pentium-M、Transmeta Crusoe 及 Nokia 手机等应用中使用（p.215）。其工作流程为：采样系统负载、进行性能预测、对电路工作状态做 DVFS 调整、再由电源管理系统维护状态。频率由高到低变化时先降频率再降电压；由低到高时先升电压再升频率（p.215）。

以图 9-26 为例：任务 A 需在 t2 前完成。在电压 V1、频率 f1 下于 t1 完成，空闲 Δt = t2 - t1 = t1 - t0，能耗 E1 = Δt·f1·V1²。若 V2 = 0.5V1，f2 = f1/2，则：

E2 = t2·f2·V2² = 2t1·(f1/2)·(V1²/4) = E1/4

即在满足时限前提下节省 75% 能耗（p.215-216）。基于硬件的 DVFS 负载计算准确性高但算法灵活性差，代表应用为 Freescale；基于软件的代表为 ARM 组织开发并用于 Linux 操作系统的 Vertigo（p.216）。DVFS 物理实现与 MSMV 类似，图 9-27 示意 I/O 工作于高电压，高性能模块 1.0V/300MHz，低性能模块 0.8V/300MHz 或 0.7V/200MHz，中间经电平转换单元转换（p.216）。

### 9.3.4 衬底偏置

进入纳米设计后泄漏电流影响显著。工艺参数误差使 MTCMOS 的“缺陷”测试分析复杂；正向有源区偏置 FBB 可降低泄漏电流并简化误差分析（p.216-217）。改变 p 区与 n 区衬底偏置电压即衬底偏置（substrate biasing）。对 PMOS 将 n 型衬底连接到高于 V_dd 的偏置电压 V_bp；对 NMOS 将 p 型衬底连接到低于 V_ss 的偏置电压 V_bn（图 9-28）（p.217）。

版图实现有两种方案（图 9-29）：

- 有源阱区（well-tap）：布放在每排标准单元两端或按一定间隔布放，节省面积，但易受闩锁（latch up）破坏。
- 标准单元内置（in-cell tap）：每个单元内部均带连接偏置电源的端口，无闩锁问题，但单元面积增大、布线困难（p.217）。

## 9.4 总结

低功耗设计的分析具有特殊性，可从功耗分析、时序分析和信号完整性分析三方面小结（p.217）。采用门控时钟、MTCMOS、PSO、MSMV 等新技术时，除静态/动态功耗分析外，还需分析不同省电工作模式下的实际功耗。PSO 可节省静态功耗 10%～50%，MSMV 与 DVFS 可节省约 50%（p.217-218）。

采用 DVFS 时时序分析更复杂，除做 setup/hold 时序外，还需做多模式多端角 MMMC 多重分析；模式可包括 core 正常工作、休眠（drowzy）、待机（dull）等，时序约束由多个 SDC 文件定义（见第 10 章）。多电压域使 RC 参数在不同电压条件下的提取更复杂，时序计算随之复杂化（p.218）。MSMV 中信号从低电压区进入高电压区时更易受噪声干扰，信号完整性分析需考虑该特殊情况（p.218）。

按功耗节省量，低功耗方案大致分为基本方法（面积优化、多阈值电压、时钟门控）和先进方法（MSMV、PSO/SRPG、DVFS）。分析方法在功耗、时序、噪声方面均有其特殊性（p.218-219）。
