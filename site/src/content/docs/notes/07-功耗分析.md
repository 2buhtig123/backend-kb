本篇为《数字集成电路物理设计》第 7 章（p.169-185）的浓缩笔记，可与原书对照阅读。

芯片功耗分析有动态分析和静态分析两种方案。在深亚微米设计（例如 0.25μm）开始后不久，对芯片做更加准确的功耗分析要求就提了出来；大部分 130nm 设计会将静态功耗分析作为投片必须检查的工序，而在小于 90nm 的设计中，尤其是低功耗设计，动态功耗和静态功耗都成为设计流程中不可缺少的重要步骤（p.169）。功耗计算有向量法和无向量法两种：有向量法借助 VCD（附录 4）或 TWF 文档（附录 14）计算功耗，无向量法则借助 TCF 文档（附录 13）计算功耗（p.169）。功耗分析与电源网络的电压降有关，供电的好坏可以用电压降来衡量，过大的电压降会引起时钟的偏差（skew）和时序违例（p.169）。

本章讨论四个问题：静态功耗（7.1）、动态功耗（7.2）、功耗分析中的电压降及其对时序的影响以及影响芯片寿命的电迁移效应（7.3）、功耗分析所需建立和产生的功耗数据方法与实用文件（7.4）。

## 7.1 静态功耗分析

静态功耗又称泄漏功耗，指电路处于等待或不激活状态时泄漏电流所产生的功耗。泄漏电流主要有 4 种（图 7-1，p.169）：①反偏二极管泄漏电流；②门栅感应漏极泄漏电流（GIDL，gate-induced drain leakage）；③亚阈值泄漏电流；④门栅泄漏电流（p.169）。

### 7.1.1 反偏二极管泄漏电流

衬底、阱、源、漏组成的晶体管中存在反偏二极管，其泄漏电流 I_reverse 是源/漏极对衬底的电流，又称源/漏极泄漏电流（source/drain leakage current，p.169-170）。以 CMOS 反相器为例，输入电压 V_in = 0 时，连接输出端下方的等效二极管反向导通产生泄漏电流；同样当 V_in = V_dd 时，连接输出端上方的等效二极管也会产生泄漏电流。计算如式（7-1）（p.170）：

I_reverse = I_sat · (e^(v_dleak/v_T) − 1)

式中：v_dleak 为加在 pn 结上的反向偏置电压；I_sat = I_sat·A 为二极管饱和电流；A 为结面积；v_T = kT/q 为热电压（室温时 v_T = 26mV）。典型的反向饱和电流密度 J_sat 在 1～5 pA/μm² 之间，随着温度 T 的升高，反向饱和电流密度会显著地增加（p.170）。

### 7.1.2 门栅感应漏极泄漏电流

在纳米工艺中，除漏极泄漏电流 I_reverse 外，还要关注栅极感应的漏极（与衬底之间）泄漏电流 I_GIDL。实验通过比较体场效应管、薄体和双栅 MOS 等多种器件，认为 I_GIDL 是由漏区与栅极感应的沟道区接近漏端的积累区之间形成的高载流子浓度反向 pn 结隧穿电流而产生的。这个泄漏电流会随晶体管工艺加工中在 Si/SiO₂ 界面处陷阱的增加而加剧，它随着晶体管衬底厚度的减少而加剧。文献介绍了多种已经获取专利的方法，包括在等离子体工艺中将栅极宽度向两边加厚形成"鸟嘴"状以及其他相关手段，比如栅电极材料的选择来减小 I_GIDL（p.170）。

### 7.1.3 亚阈值泄漏电流

当栅极偏置电压很低时，沟道载流子受到源端的势垒的阻挡，源漏间的电流很小；当栅极电位 V_GS 升高时，会降低这个势垒高度，导致沟道电流受源漏电压的影响，这个机理被称为 DIBL（drain-induced barrier lowering）（p.170）。亚阈值漏电流（称为亚阈值电流，subthreshold current）主要由沟道电子的扩散引起，在 5V 工作条件下它的值为 0.1～0.5nA。亚阈值泄漏电流为（p.170）：

I_SB = I_S · e^((V_GS − n·v_T)/v_T) · (1 − e^(−V_DS/v_T))　　（7-2）

I_S = β₀ · v_T² · e^1.8　　（7-3）

式中经验公式指数 n = 1.4～1.5，与工艺有关。从式（7-2）看出，当 V_GS 为零时，I_SB 也为零；只要 V_GS 大于 v_T 几倍以上，I_SB 很快就上升到最大值（p.170）。

### 7.1.4 门栅泄漏电流

在纳米尺度 CMOS 中，栅介质（通常是 SiO₂）越来越薄，门栅泄漏电流 I_gate 产生的功耗越来越受重视。一般认为与漏极、漏极泄漏电流相关的泄漏电流功率相比，栅泄漏电流功率要大得多（p.171）。2005 年 UMC 就曾报道 90nm 工艺中通过添加 N 形成 SiON（silicon oxy-nitride）材料，使栅介质的有效氧化厚度 EOT（effective oxide thickness）达到 1.2nm 或 4 个氮原子层厚度，相应的电流密度仅有 10A/cm²；65nm 工艺条件下，某个 MOS 晶体管宽 100nm，其实际 I_gate 则小于 1nA（p.171）。

Intel 于 2002 年设计了第一个三栅极（tri-gate）晶体管并制造在 SOI 或传统体硅衬底上；AMD 和 IBM 合作自 2003 年开始开发 SOI 方案，用于第 8 代技术 90nm 工艺；22nm 节点中可能采用三栅晶体管解决阈值漏电流问题。根据 65nm 的数据，三栅晶体管技术使 NMOS 泄漏电流 I_gate·I_leak 减少 30%、PMOS 增加 60%，高压关下的过大漏电流（off-state leakage current）大幅减少（p.171）。另一种方案是采用高介电常数 k 和金属电极的栅结构（称为栅堆叠层，gate stack）去降低泄漏电流，即取代传统的 SiO₂ 和多晶硅，例如 Intel 2007 年发布的 Penryn 45nm 设计就采用了高 k 金属栅（HkMG）技术（p.171）。

### 7.1.5 静态功耗分析

芯片的静态功耗是由泄漏电流引起的泄漏功耗（p.171）：

P_leakage = V_DD · I_leakage　　（7-4）

总泄漏电流 I_leakage 可表示为（假设端口 G 与 D 连在一起，B 与 S 连在一起）（p.171）：

I_leakage = I_reverse + I_GIDL + I_SB + I_gate　　（7-5）

## 7.2 动态功耗分析

动态功耗指芯片在工作中、晶体管处于跳变状态时所产生的功耗，主要由动态开关电流引起的动态开关功耗 P_sw（也称为跳变功耗）以及短路电流产生的短路功耗 P_sc 两部分组成（p.171）。

### 7.2.1 开关功耗

开关功耗 P_sw 是在逻辑门的开关事件中所产生的功耗，即在 CMOS 逻辑门输出节点电压产生一个逻辑转换时，电源对输出节点电容的充电所产生的功耗。在充电过程中，输出节点的电压通常从 0 完全转换到 V_DD，电源在一个充放电的周期中提供的能量一半将以热的形式在 PMOS 管导通时被消耗掉——动态功耗主要是逻辑门的输出电容引起的（p.171-172）。

逻辑门的输出电容主要包括三个部分（p.172）：自身输出节点电容 C_drain、总的互连电容 C_interconnect、被驱动门的输入电容 C_input。其中 C_drain 由晶体管漏极扩散区引起的寄生电容决定；门之间的互连线决定了 C_interconnect 的大小；C_input 主要由连接在输出晶体管的栅氧化层电容决定（p.172）：

C_L = C_drain + C_interconnect + C_input　　（7-6）

假设每个时钟周期 T 内 CMOS 门输出节点经历一次电平的转换，CMOS 电路的动态平均功耗 P_avg,sw 由式（7-7）表示：P_avg,sw = (1/T)∫₀ᵀ v(t)·i(t)dt。以 CMOS 反相器为例，实际功耗为电平信号转换时对 NMOS 和 PMOS 充放电两次所需功耗（式 7-8）。求积分得平均动态开关功耗为 P_avg,sw = (1/T)·C_L·V_DD² = f_sw·C_L·V_DD²，其中转换频率 f_sw = 1/T（p.172）。

引入节点转换因子 α_T，它是一个统计值，表征了单位时钟周期内的门翻转概率。平均转换频率 f_avg 会低于时钟频率 f_CLK，即 f_avg = α_T·f_CLK；通常节点的电压 V_i 小于供电电压 V_DD，更精确的平均动态开关功耗计算公式为（p.172）：

P_avg,sw = (Σᵢ₌₁ⁿ α_Ti · C_i · V_i) · V_DD · f_CLK　　（7-9）

式中：α_Ti 为对应节点的节点转换因子；C_i 为电路中每个相连接节点上的输出电容；n 为节点数。由式（7-9）可得：平均动态开关功耗与节点的负载电容、节点的电压、供电电压以及节点的翻转频率成正比（p.172）。

由于式（7-9）的计算较复杂，而实际上每充电或放电翻转一次晶体管的动态开关功耗为 P_dynamic,sw = (1/2)P_avg,sw，通常用式（7-10）来计算（p.172）：

P_dynamic,sw = (1/2) · α · f_CLK · C_L · V_DD²　　（7-10）

动态开关功耗 P_dynamic,sw 只考虑电路处于开关状态时寄生负载电容所引起的功耗，与输入信号的上升时间和下降时间即输入信号的波形无关（p.172）。

### 7.2.2 短路功耗

当 CMOS 逻辑门被有固定上升沿与下降沿（slew）的输入电压驱动时，在开关过程中 PMOS 和 NMOS 晶体管会在短时间内同步导通，从而在电源和地之间形成一条直流通路，并产生短路（sc，short circuit）功耗 P_sc。该通路上的电流称为短路电流。当输入电压 V_in 上升到阈值电压 V_TH 时，NMOS 管开始导通，而 PMOS 管直到输入电压达到 V_DD − V_TH 之前保持导通，在此时间区间内 NMOS 管和 PMOS 管同时导通，产生短路电流 I_sc（图 7-4，p.173）。

该短路电流的表达式为（p.173）：

I_sc = (1/12) · (k · τ · f_CLK / V_DD) · (V_DD − 2V_TH)³　　（7-11）

其中 k = k_n = k_p 为 NMOS 和 PMOS 的介电常数（管子的导电系数），τ = τ_rise = τ_fall = τ 为输入波形的上升沿和下降沿时间，V_TH,n = V_TH,p = V_TH 为逻辑门的开启阈值电压，f_CLK 为时钟频率。由此短路电流计算短路功耗 P_sc 的表达式为（p.173）：

P_sc = I_sc · V_DD = (1/12) · k · τ · f_CLK · (V_DD − 2V_TH)³　　（7-12）

实际应用中，常用 PWL（piece-wise linear）模型来近似表达短路电流（p.173）。

### 7.2.3 动态功耗分析与总功耗

动态功耗由开关功耗和短路功耗两部分组成，即 P_dynamic = P_dynamic,sw + P_sc。EDA 工具对动态功耗的分析也是基于这两个部分，但在实际应用中将开关功耗分成器件功耗和网线负载功耗两部分，采用图 7-7 所示的功耗模型（p.174）。

器件功耗分为泄漏功耗和内部功耗两部分，即 P_device = ΣP_leakage + ΣP_internal，总功耗 P_total = ΣP_device + ΣP_net，有（p.174）：

P_total = ΣP_leakage + ΣP_internal + ΣP_net　　（7-13）

式中：n 为设计中所使用的最小设计单元的数量；m 为网线的条数。此处的泄漏功耗 P_leakage 是工具根据设计中使用的标准单元库、IP 核或用户定义模块的时序库中对功耗的定义计算得到的；内部功耗 P_internal 即 7.2.1 节所定义的动态开关功耗 P_dynamic,sw 的一部分和 P_sc，它也是通过查找工艺库中对于功耗的定义而得到的。在工艺库中，对于不同斜率的输入波形以及输入负载，可以查表得到相应的内部功耗，有些库中对不同上升沿和下降沿的功耗都有相应的值（p.174）。

对于电容的充放电，由式（7-8）和式（7-9）可知，对于由寄存器组成的时钟，实际上只有半个周期会消耗功率，我们取节点转换因子 α_T 为 0.5，在网线上消耗的功耗如式（7-14）所示（p.175）：

P_net = 0.5 · C_L · V_DD² · T_net　　（7-14）

式中 C_L 由式（7-6）给出；T_net 由网线频率决定。在逻辑综合阶段 C_L 的值可以通过 WLM 定义，这与经过布局布线后的网线电容值存在一定的误差；在物理实现后期则采用分布参数提取工具从而得到精确值，综合阶段和物理实现阶段所计算的功耗估值会有差异。V_DD 即为工作电压。器件的功耗包含了短路功耗和动态开关功耗两部分，网线负载上所消耗的只有动态开关功耗（p.175）。

动态功耗分析用无向量法时需要使用 SPF、TWF、VCD 中的动态信息或 TCF 及 SDC 文件；以 VCD 作向量法的动态功耗需要完整的 VCD、DSPF、TWF 及 SDC 文件（p.175）。

## 7.3 电压降分析与电迁移分析

理论设计假设芯片内的电源为理想电源，能在瞬间给芯片上的所有门单元与宏单元提供足够大的电流，使芯片上的电压保持稳定的值。但由于芯片内部供电网络寄生参数（电阻、电容、电感）的存在，导致电源从输入输出接口（PAD，封装称之为凸点）到达芯片内部各点的电势不同，其差值称为电压降（IR Drop）。电压降有内部节点的电源电压 V_DD 低于供电凸点的电压降和内部节点的地电压 V_ss 高于供电凸点的"地弹"（ground bounce）两种（p.175）。

电压降的存在会影响延迟的变化，降低噪声容限的值，从而导致芯片时序违例，甚至产生功能失效。随着集成电路规模的增加和工艺的发展，电压降问题变得尤为突出，分析由封装引起的电压降并将其控制在合理的范围内是芯片设计首要考虑的问题（p.175）。

### 7.3.1 压降与供电网络

供电网络在芯片内部主要由电源凸点（位于 PAD）、电源环（power-ring）以及电源分支（power-trunk or power strap）组成（图 7-9，p.175-176）。通过对供电网络的静态分析发现，电压降往往是由于多种原因引起的，如连接电源线通孔的遗漏或不足、电源线宽度不够、电源规划的不合理等（p.176）。

根据电源网格结构，芯片的供电网络电压降可以根据基尔霍夫定律（Kirchhoff Laws）的第一定律（电压定律，又称为回路规则 loop rule）和第二定律（电流定律，又称为节点规则 junction rule）来计算（p.176）：

Σ ΔV_i = 0，　I₁ = I₂ + I₃　　（7-15）

计算电压降的基本方法是由供电网络分布，首先分别提取电源网格的电阻 R 和电流节点处的平均节点阀门电流（tap current）I_avg，再建立电源网格视图。图 7-10 为用布图视图（floorplan view）作电压降分析的示意图（p.176）。

### 7.3.2 压降与封装

在纳米设计中，除了计算芯片内的电压降外，还要考虑与封装相关的电压降。总电压降的大小 V_total 由电源凸点到逻辑门单元之间等效电阻 R 及封装导线的电感值 L 决定，并由欧姆定律决定 V_R,chip = I·R，I 为通路的电流，V_L = L·di/dt，则 V_total 值如式（7-16）所示（p.176-177）：

V_total = V_R,chip + V_L = I·R + L·di/dt　　（7-16）

封装电感对电压降的影响如图 7-11 所示的两种封装形式：DIP（dual in-line）封装的封装电感为 1～2nH，BGA（ball grid array）封装的封装电感为 0.1～0.2nH（p.177）。假设 20mA 的电流在 200ps 内通过电源网络给内部节点供电，其消耗在 DIP 和 BGA 封装导线上的电压降和地弹的总值（作用于两条线路）分别计算得 400mV 和 40mV（p.177）：

V_L(DIP) = 2 × L·di/dt = 2 × 2nH × (20mA/200ps) = 400mV
V_L(BGA) = 2 × L·di/dt = 2 × 0.2nH × (20mA/200ps) = 40mV　　（7-17）

由此可见，随着工艺的发展，供电电压在下降，从 5V、3.3V、2.5V、1.8V 到 1.2V，封装导线所产生的电压降变得尤为突出，需要通过封装形式的改进减小电压降的值。另外，在布图时，可以通过添加去耦电容的方法来改善电压降的分布。地弹值计算方法与电压降的计算方法一致，在芯片设计时，需要将电源和地弹总电压降控制在供电电压的 5% 以内，以便保证芯片的性能和功能（p.177）。

### 7.3.3 压降与时序违例

电压对于芯片性能的影响非常大，一般情况下，5% 的电压降会增大 10%～15% 的线延迟（p.177）。以 SMIC 0.13μm 工艺为例，总延迟 t_TPD 的计算如式（7-18）所示（p.178）：

t_TPD = (K_process)·[1 + (K_volt·ΔV_dd)]·[1 + (K_temp·ΔT)]·t_typical　　（7-18）

式中：K_process 为工艺因子，typical 值为 1，fast 值为 0.823，slow 值为 1.267；K_volt 为电压因子，在 (1.2～1.32) 时为 −1.033/V，在 (1.2～1.08) 时为 −1.577/V；K_temp 为温度因子；t_typical 为典型条件下的延迟（p.178）。

从式（7-18）可以看出，当电压降为 5% 时，则延迟值为 t_TPD = 1 × [1 + (1.577 × 0.05 × 1.2)] × 1 × t_typical = 1.095 × t_typical，即延迟增加 9.5%（p.178）。

延迟值的增加会造成时序违例的产生，它可以引起 setup 和 hold 违例：如果电压降或延迟是位于数据路径，它可能会产生 setup 的违例；如果电压降或延迟是位于时钟路径，它可能会产生 hold 的违例（图 7-13，p.178）。

书中给出某设计时钟周期为 3ns 的算例（表 7-1，p.179）：在没有电压降时，其工作主频可以达到 318MHz，在 5% 电压降时主频为 294MHz，如果有 10% 的电压降，则主频只有 272MHz。可见在高频数字电路中，降低电压降对于提高芯片的性能有着至关重要的作用（p.179）。

### 7.3.4 电迁移与电流密度

电迁移在设计现场分析中尚未很好定义，近来它也被称为"信号电迁移"，相对于电源线分析，也就是对信号线做分析。有人认为它是分析交流 AC 的 I_rms（均方根电流），也就是线自热（wire self-heat）；也有人认为它是分析直流 DC 信号的电迁移（p.179）。

对于作为互连的金属层来说，在一定的制造工艺下，它上面所能允许流过的最大电流是有一定限度的，否则过大的电流将使金属连线断裂，导致芯片失效。这种由于电流所引起的电路失效现象称为 EM（electromigration，电迁移），或称作焦耳热效应（Joule heating）。如图 7-14 所示，电源网格在长期的直流通电时，金属原子发生实观迁移，在阳极附近堆积，严重时会形成小丘或突起，同时在阴极附近的导线内出现空洞；在高温条件下，金属离子变得"活泼"，大量电子的猛烈撞击就很容易推动这种迁移（p.179）。

电源网格的电迁移由平均电流密度、金属宽度以及孔的大小决定。在检查电源网格是否存在电迁移隐患时，是通过计算通过网格的直流电流密度值 J，然后与标称的直流电流密度 J_max 相比较：当 J > J_max 时，不符合设计规则；当 J < J_max 时则认为该电源网格是安全的（p.179）。

电迁移容限的测量方法有多种，如漂移速度法、低频噪声法、电阻模型模拟等，其中最常用的是寿命测试法，即测量一定数量的相同样品在规定条件下的失效时间，取它们的中值作为这批样品的平均失效时间（MTTF，mean time to failure）。1969 年 Black 根据实验和理论结果总结出了著名的 Black 方程（p.180）：

t_MTTF = (A / J²) · exp(−E/kT)　　（7-19）

式中：A 为经验适用常数，当采用加速测量方法时其值为 2×10⁷ h·cm²/A；J 为电流密度（A/cm²）；E 为电势能级，其值为 0.6～1.4eV（铝）；k 为玻耳兹曼常数，8.616×10⁻⁵ eV/K；T 为节点温度（K）。由式（7-19）可以看出，其寿命与电流密度的平方成反比。设 MTTF 为芯片有 50% 的机会失效时得 t_50，则此时最大电流密度为（p.180）：

J_max = sqrt(A·exp(−E/kT) / t_50)　　（7-20）

书中例 7-1：假定期望芯片的寿命是 10 年，取 10 倍保险系数，设金属 Al 的电势能级为 0.85eV，则可得 J_max = 8.95×10⁵ A/cm²（p.180）。与铝工艺相比较，铜线工艺在电迁移方面有着较好的抗性。铜孔工艺的抗 EM 效应并非非常理想，如 SMIC018μm 铝线工艺的 J_max 值为 1×10⁶ A/cm²，0.13μm 的铜工艺 J_max 值为 1.9×10⁶ A/cm²（p.180）。

另外，根据设计约束中 maxCapacitance 和 maxTransition 的约束条件，就功耗分析工具而言希望这两种约束是对频率做约束：每单位频率的 maxCapacitance 能避免直流的电迁移，每单位频率的 maxTransition 能保证实现信号完整的替换。在物理库中的 LEF 技术文件包含有布局布线的技术定义：对于每层布线，它含有与频率有关的交流电流密度值，用以约束交流的 J_max；它同时含有与面积有关的平均直流电流密度值，用以约束直流的电迁移（p.180）。

## 7.4 功耗分析数据与文件

功耗分析贯穿在芯片设计全流程中：当对芯片布局时，首先要设计电源网络，并分析电源，从而评估电源网络性能；在芯片完成布线后，还要对芯片进行 sign-off 的功耗分析、电压降分析和电迁移（包括电流密度分析）等（p.180）。功耗分析需要建立相应的数据库，并且借助与功耗相关的文件来有效控制和处理这些数据。

### 7.4.1 功耗分析与功耗数据

做静态功耗分析可以用简化了的信号网络的翻转信息 TCF（toggle count format）文件；做动态功耗分析时需要输入两个重要信息：电源凸点的位置分布信息和动态功耗仿真所用的 VCD（value change dump）文件或者 TWF（timing window format）文件（p.181）。

时序库文件中包含每个单元的功耗数据，并以功耗输入信号转换时间和输出信号负载的函数表示。时序库文件中其他与功耗相关的内容还有功耗单位（例如 nW）、能量模型、静态功耗，它还保留了与信号完整性相关的功耗语法（p.181）。书中例 7-2：假定逻辑门"AND2D1"的输入 A1 的 slew = 18ps，Z 的输出负载为 0.336pF，根据式（7-13）计算器 AND2D1 的内部功耗为 P_internal,A1 = 0.5 × p_rise + 0.5 × p_fall = 0.5 × 0.0061 + 0.5 × 0.0059 = 0.006（p.181）。

### 7.4.2 电源网格视图库

电源网格视图 PGV（power grid view）有多种形式，它是用来分析芯片电压降效应的一种重要的库文档格式。通常功耗分析工具都会首先使用时序库中所定义的功耗信息计算分析，当库中没有功耗信息时，则可以用 PGV 库予以取代。用 PGV 库计算功耗的精度不很高。它的基本计算方法是：根据供电网络分布，首先分别提取电源网格的电阻 R 和电流节点处的平均节点阀门电流（tap current）I_avg，而后再建立电源网格视图库（图 7-15，p.182）。其中节点阀门电流可以是静态电流也可以是动态电流（p.182）。

各种功耗网格视图包括用于电压降或功耗分析不同阶段的端口视图、布图视图、详细视图、摘要视图和简化视图（图 7-16，p.182）：端口视图用于标准逻辑单元的标准定；布图视图对电源网格进行预估以计算模块内部功耗；详细视图最为准确完整，包括电源轨道的 RC 值、节点阀门电流的平均分布和去耦电容以代表模块内部功耗；摘要视图包括端口间的 RC 简化数值和去耦电容，用于顶层功耗和静态功耗分析；简化视图包括摘要端口间 RC 简化数值和去耦电容，用于顶层 debug 用途。端口视图和布图视图可以由 LEF 产生，其他视图必须由 GDSII 产生（p.182）。

### 7.4.3 通用功耗格式文件与应用

面向低功耗设计，EDA 工具提供商强调对整个流程进行优化来实现低功耗自动管理的理念，同时为简化设计的复杂性相继推出统一的功耗格式文件。由 Cadence 公司开发、Si2（silicon integration initiative）的低功耗联盟（LPC）管理的通用功率格式（CPF，common power format）首先于 2005 年向行业开放；Synopsys 公司后来也开发了统一功耗格式（UPF，unified power format）在 2007 年 2 月底作为一项 Accellera 标准推出（p.182-183）。

CPF 允许用户在整个 RTL-to-GDSII 设计流程中定义功耗设计意图和约束条件，使用 Tcl 脚本文件，用户可以用其中的命令完成诸如建立和管理独立电源域、确定隔离和保持、建立电平漂移、定义与电源相关的规则和约束条件等工作。虽然当前的工具可以使用多种功耗格式和规范，但人们希望在整个设计流程中采用统一的功耗表达方式。CPF 文件已经首先用于 RTL 阶段的低功耗规范设计、逻辑等效检查、低功耗物理实施和功耗分析中（p.183）。书中例 7-3 给出了 CPF 代码定义和功耗架构：create_power_nets、create_ground_nets、define_power_switch_cell、define_isolation_cell、define_level_shifter_cell、create_power_domain、create_isolation_logic、create_level_shifter_logic 等命令描述了 CPU 中 ALU 电源域在空闲时被关闭以节省功耗的设计（p.183-184）。

## 7.5 总结

由于低功耗设计的重要性不断地增长，本章首先对与静态功耗紧密相关的泄漏电流做了讨论。静态功耗分析和动态功耗分析已经成为两大类成熟的方法，利用它们可以针对芯片物理设计中最关心的电压降和电迁移两个常见问题进行计算并对设计进行约束。结合时序库建库的概念和方法，还介绍了相关的功耗库数据表和电源网格数据库的类型以及它们在功耗分析的作用。功耗分析可以独立进行，也可以在静态时序分析之前或者之后进行（p.184）。

应当注意到用电源网格视图方法作电源网络分析是功耗分析的一项重要任务和组成部分。与功耗分析相关的论题还有热电子效应在本章未及讨论：对于器件本身，当应用条件极差或者芯片的使用寿命是重要因素时，热电子效应的分析则必不可少（p.184）。
