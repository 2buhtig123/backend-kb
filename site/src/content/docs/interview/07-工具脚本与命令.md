### 1.3 Tcl 基础

Tcl（Tool Command Language）几乎所有 EDA 工具都支持，语法简单：

```tcl
# 变量
set var "hello"
puts $var                    ;# 输出 hello

# 数组
set arr(key) "value"
puts $arr(key)

# 流程控制
for {set i 0} {$i < 10} {incr i} {
  puts "i = $i"
}

# 函数
proc my_proc {arg1 arg2} {
  return [expr $arg1 + $arg2]
}

# 列表
set lst {a b c d}
llength $lst                 ;# 4
lindex $lst 0                ;# a
```

### 题 1：Tcl 里 `set`、`puts`、`expr` 有什么区别？

**参考答案**：

| 命令 | 作用 | 示例 |
|---|---|---|
| **`set`** | 变量赋值 | `set x 10` |
| **`puts`** | 打印输出 | `puts "Hello"` |
| **`expr`** | 算术/逻辑表达式求值 | `expr {$x * 2 + 1}` |

**关键细节**：

```tcl
set a 10                     ;# a = 10
set b "20"                   ;# b = "20"（字符串）

expr $a + $b                 ;# 30（自动转数字）
expr {$a + 1}                ;# 11（大括号保护变量）

puts "Value: $a"             ;# Value: 10
```

**加分点**：
- 提到 "expr 里变量必须带 $，且建议加大括号"
- 提到 "puts 默认输出到 stdout"
- 提到 "set 也可以不赋值（用作读变量）"

### 题 8：怎么从 timing report 里提取关键路径？

**参考答案**：

**Perl 提取 WNS/TNS 脚本**：

```perl
#!/usr/bin/perl
use strict;
use warnings;

open my $fh, '<', 'timing.rpt' or die $!;
my ($wns, $tns) = (undef, 0);
my @violations;

while (<$fh>) {
  # WNS 提取
  if (/^\s*slack \((\S+)\)/) {
      my $slack = $1;
      if (!defined $wns || $slack < $wns) {
          $wns = $slack;
      }
      if ($slack < 0) {
          $tns += $slack;
          push @violations, $slack;
      }
  }
    
  # 路径信息
  if (/Startpoint:\s+(\S+)/) {
      # 记录路径
  }
  if (/Endpoint:\s+(\S+)/) {
      # 记录路径
  }
}

print "WNS: $wns ps\n";
print "TNS: $tns ps\n";
print "Violating paths: ", scalar @violations, "\n";
```

**Python 版本（更简洁）**：

```python
import re

wns = None
tns = 0
violations = 0

with open('timing.rpt') as f:
  for line in f:
      m = re.search(r'slack \((\S+)\)', line)
      if m:
          slack = float(m.group(1))
          if wns is None or slack < wns:
              wns = slack
          if slack < 0:
              tns += slack
              violations += 1

print(f"WNS: {wns} ps")
print(f"TNS: {tns} ps")
print(f"Violations: {violations}")
```

**加分点**：
- 提到 "现代工具可以直接输出 JSON/Tcl 格式——避免正则解析"
- 提到 "Innovus 用 `report_timing -machine_readable` 输出可解析格式"
- 提到 "PT 用 `report_timing -delay max > report.txt` + 解析"

### 题 10：常用的 SDC 命令有哪些？请举例。

**参考答案**：

**SDC 核心命令**：

```tcl
# 时钟定义
create_clock -name clk -period 10 [get_ports clk]   ;# 主时钟
create_generated_clock -name clk_div -divide_by 2 \
  -source [get_ports clk] [get_pins u_div/Q]        ;# 衍生时钟

# 输入延迟
set_input_delay -clock clk -max 2.0 [get_ports din]   ;# max = 2ns
set_input_delay -clock clk -min 0.5 [get_ports din]   ;# min = 0.5ns

# 输出延迟
set_output_delay -clock clk -max 3.0 [get_ports dout]
set_output_delay -clock clk -min 1.0 [get_ports dout]

# 驱动强度
set_driving_cell -lib_cell BUFX2 -pin X [get_ports din]

# 负载
set_load -pin_load 0.05 [get_ports dout]

# 时序例外
set_false_path -from [get_clocks clk1] -to [get_clocks clk2]
set_multicycle_path -from A -to B -setup 2
set_max_delay -from A -to B 5.0

# 工作条件
set_operating_conditions -max slow_125c -min fast_0c

# 模式
set_case_analysis 0 [get_ports scan_mode]
```

**加分点**：
- 提到 "set_false_path 在 STA 中跳过路径——不能乱用"
- 提到 "multicycle_path 配 hold 系数 -hold N"
- 提到 "SDC 是工具的核心——错 SDC = 错 STA"

### 题 11：项目里需要批量跑 10 个 corner 的 STA 并生成报告，怎么自动化？

**参考答案**：

**Tcl 脚本框架**：

```tcl
# scripts/run_sta.tcl
set corners { 
  {slow_125c   max 0.95 1.10}
  {slow_-40c   max 0.95 1.10}
  {fast_125c   min 0.95 1.10}
  {typical_25c max 1.00 1.00}
}

foreach corner $corners {
  set name    [lindex $corner 0]
  set min_max [lindex $corner 1]
    
  # 1. 重置工具状态
  remove_design -all
    
  # 2. 加载库
  read_libs "${name}.lib"
    
  # 3. 读设计
  read_verilog design.v
  link_design top
    
  # 4. 读 SDC
  read_sdc constraints.sdc
    
  # 5. 读 SPEF
  read_parasitics "${name}.spef"
    
  # 6. 跑 STA
  update_timing -full
    
  # 7. 输出报告
  report_timing -delay $min_max -path_type full > "reports/${name}_${min_max}.rpt"
  report_analysis_coverage > "reports/${name}_coverage.rpt"
}
```

**Python 包装**：

```python
# scripts/run_all_corners.py
import subprocess

corners = ['slow_125c', 'slow_-40c', 'fast_125c', 'typical_25c']
for c in corners:
  cmd = ['pt_shell', '-f', f'scripts/run_sta_{c}.tcl']
  result = subprocess.run(cmd, capture_output=True, text=True)
    
  # 检查 WNS / TNS
  wns, tns = parse_timing_report(f'reports/{c}.rpt')
  if wns < -100 or tns < -1000:
      send_email_alert(f"{c} 违例！WNS={wns}, TNS={tns}")
```

**加分点**：
- 提到 "MMMC (Multi-Mode Multi-Corner) 用 `create_corner` + `set_active_corner`"
- 提到 "PT 里 `set_multi_scenario` 是 MMMC 的核心"
- 提到 "自动化报告要包含 slack histogram / critical path summary"
